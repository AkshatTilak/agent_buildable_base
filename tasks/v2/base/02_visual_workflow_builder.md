# Base Task: Visual Workflow Builder

## Objective
Implement a robust drag-and-drop LangGraph visual editor using ReactFlow to allow dynamic creation and modification of agent workflows.

## Business/System Value
Hardcoding LangGraph orchestrations limits the platform's flexibility. Providing a visual interface allows operators to easily map out agent interactions, define fallback chains, and visually understand the complex routing logic of the system.

## Complexity Rating
High (Requires mapping complex backend LangGraph graph structures to a visual ReactFlow state and back).

## Subtask Registry
* `[ ] sub/workflow_reactflow_setup.md` — Initialize ReactFlow canvas with custom Node and Edge types for Agents.
* `[x] sub/workflow_graph_translation.md` — Create a translation layer that converts ReactFlow JSON state into executable LangGraph code/configuration.
* `[ ] sub/workflow_ui_controls.md` — Build sidebars and property panels to edit node details (conditions, fallback routing).
* `[x] sub/workflow_backend_sync.md` — API endpoints to save, load, and execute workflows generated by the visual builder.
