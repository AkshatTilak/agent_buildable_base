# Version 4 (v4) Task SOP & Hierarchy (`tasks/v4/tasks.md`)

This document defines the hierarchical structure and lifecycle of all Version 4 (v4) UI & Layout Polish tasks.

---

## 1. The Task Hierarchy (v4)

All v4 project work is divided into four distinct layers within the `tasks/v4/` directory:

### I. `goal/` (The North Star)
* **Purpose:** Defines the absolute final objective of the v4 UI layout overhaul.
* **Scope:** Contains `tasks/v4/goal/ui_spacing_layout_overhaul.md`.

### II. `base/` (Architectural Milestones)
* **Purpose:** Defines foundational objectives for spacing, typography, grid gap optimization, and padding decluttering.
* **Scope:** `tasks/v4/base/01_frontend_spacing_layout.md`.

### III. `sub/` (Granular Execution Units)
* **Purpose:** Granular implementation subtasks in `tasks/v4/sub/`.
