# Base Task 3: UI Cleanup, Empty States & Non-Core Dependencies

## What
Clean up the React frontend by removing legacy code, adding polished empty-state screens for fresh platform startups, and enhancing the Infrastructure UI to display non-core service status, direct links, and launch commands.

## Why
Starting the platform clean in v6 resulted in broken UI widgets due to missing default data. A clean startup must offer clear call-to-actions, and non-core tools (pgAdmin, Redis Insight, etc.) should be rendered with actionable launch instructions instead of failing embedded views.
