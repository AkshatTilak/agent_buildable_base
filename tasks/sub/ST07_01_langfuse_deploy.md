# ST07_01: Validate Langfuse Docker Deployment

## Parent Link
`base/BT07_observability.md`

## Actionable Steps
- [ ] Step 1: Verify Langfuse server starts with correct DATABASE_URL
- [ ] Step 2: Verify NEXTAUTH_SECRET and SALT are configured
- [ ] Step 3: Access Langfuse web UI at http://localhost:3000
- [ ] Step 4: Create initial project and generate API keys
- [ ] Step 5: Verify telemetry is disabled (TELEMETRY_ENABLED=false)

## Dependencies
- PostgreSQL container running

## Definition of Done
Langfuse web UI accessible, project created, API keys generated for SDK integration.
