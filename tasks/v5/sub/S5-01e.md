## Scope

Expand the database schema to support granular per-metric eval results and additional score columns on `EvalRunHistory`. This is a prerequisite for all other EvalOps subtasks.

## Actionables

- [ ] Modify `EvalRunHistory` in [`common/models/database.py`](file:///c:/Akshat/ContAIned/common/models/database.py):
  - Add columns: `recall_score` (Float, nullable), `precision_score` (Float, nullable), `context_recall_score` (Float, nullable), `answer_relevance_score` (Float, nullable), `hallucination_score` (Float, nullable), `toxicity_score` (Float, nullable), `bias_score` (Float, nullable), `framework_used` (String(20), nullable — "ragas"/"deepeval"/"both"), `total_test_cases` (Integer, nullable), `passed_count` (Integer, nullable), `failed_count` (Integer, nullable)
- [ ] Add new model `EvalMetricResult` in `common/models/database.py`:
  ```python
  class EvalMetricResult(Base):
      __tablename__ = "eval_metric_results"
      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      run_id = Column(String(36), ForeignKey("eval_run_history.id", ondelete="CASCADE"), nullable=False, index=True)
      test_case_id = Column(String(36), ForeignKey("eval_test_cases.id", ondelete="SET NULL"), nullable=True, index=True)
      metric_name = Column(String(100), nullable=False)  # e.g. "faithfulness", "toxicity"
      metric_score = Column(Float, nullable=True)
      metric_reason = Column(Text, nullable=True)  # DeepEval provides reasons
      framework = Column(String(20), nullable=False)  # "ragas" or "deepeval"
      threshold = Column(Float, nullable=True)
      passed = Column(Boolean, nullable=True)
      created_at = Column(DateTime, default=datetime.utcnow)
  ```
- [ ] Generate Alembic migration: `alembic revision --autogenerate -m "v5_evalops_schema_expansion"`
- [ ] Verify migration runs cleanly: `alembic upgrade head`
