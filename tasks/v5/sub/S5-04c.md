# S5-04c: Playground Session Persistence

> **Parent:** B5-04 (Model Playground)  
> **Status:** `[ ]`  
> **Complexity:** 🟢 Low  
> **Owner:** `gateway`, `common/models`

---

## Scope

Save, load, list, and delete playground chat sessions.

## Actionables

- [ ] Add `PlaygroundSession` model to `common/models/database.py`:
  ```python
  class PlaygroundSession(Base):
      __tablename__ = "playground_sessions"
      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      user_id = Column(String(36), ForeignKey("users.id", ondelete="SET NULL"), nullable=True)
      name = Column(String(200), nullable=False)
      model_id = Column(String(200), nullable=True)
      system_prompt = Column(Text, nullable=True)
      messages_json = Column(JSON, nullable=False, default=list)
      attachments_json = Column(JSON, nullable=True, default=list)
      temperature = Column(Float, nullable=True)
      max_tokens = Column(Integer, nullable=True)
      created_at = Column(DateTime, default=datetime.utcnow)
      updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
  ```
- [ ] Add API endpoints in `gateway/api/playground.py`:
  - `GET /api/playground/sessions` — list user's sessions (sorted by updated_at desc)
  - `POST /api/playground/sessions` — save session (name, model_id, system_prompt, messages, attachments)
  - `GET /api/playground/sessions/{id}` — load session
  - `PUT /api/playground/sessions/{id}` — update session (auto-save)
  - `DELETE /api/playground/sessions/{id}` — delete session
- [ ] Generate Alembic migration
- [ ] Add test: `gateway/tests/test_playground_sessions.py`

## Key Design Decisions

- `user_id` nullable (no auth) — when auth disabled, sessions are global
- Messages stored as JSON array: `[{role, content, tokens?, attachment_ids?}]`
- Auto-name sessions from first user message (truncated to 100 chars) if no name provided
