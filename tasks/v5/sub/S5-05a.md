> **Parent:** B5-05 (MCP Integration Hub)

## Scope

Create DB models for MCP server registration and CRUD API with periodic health checking.

## Actionables

- [x] Add DB models to `common/models/database.py`:
  ```python
  class MCPServer(Base):
      __tablename__ = "mcp_servers"
      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      name = Column(String(100), nullable=False, unique=True)
      url = Column(String(500), nullable=False)
      transport = Column(String(30), nullable=False, default="sse")  # sse / stdio / streamable_http
      auth_type = Column(String(20), default="none")  # none / bearer / api_key
      auth_token_encrypted = Column(Text, nullable=True)  # encrypted at rest
      is_internal = Column(Boolean, default=False)  # auto-registered internal servers
      is_active = Column(Boolean, default=True)
      health_status = Column(String(20), default="unknown")  # healthy / unhealthy / unknown
      last_health_check = Column(DateTime, nullable=True)
      created_at = Column(DateTime, default=datetime.utcnow)
      updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
  ```
- [x] Create `gateway/api/mcp_manager.py`:
  - `GET /api/mcp/servers` — list all registered servers (with health status)
  - `POST /api/mcp/servers` — register external MCP server
  - `PUT /api/mcp/servers/{id}` — update config
  - `DELETE /api/mcp/servers/{id}` — remove (block deletion of internal servers)
  - `POST /api/mcp/servers/{id}/health` — trigger manual health check
- [x] Health check implementation:
  - For SSE transport: HTTP GET to server URL, check for valid MCP response
  - For stdio: attempt connection, check process is running
  - Background task: periodic health checks every 5 minutes for active servers
- [x] Auth token encryption: use Fernet symmetric encryption with `JWT_SECRET_KEY`
- [x] Generate Alembic migration
- [x] Add test: `gateway/tests/test_mcp_manager.py`
