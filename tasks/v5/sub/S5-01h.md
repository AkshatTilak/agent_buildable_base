# S5-01h: Frontend — Results Dashboard (Metrics Cards, Trend Charts, Drill-Down)

> **Parent:** B5-01 (EvalOps Deep Integration)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`

---

## Scope

Replace the current mock-data eval dashboard with a real metrics dashboard powered by the stats/trends APIs.

## Actionables

- [ ] Create `frontend/src/components/eval/MetricsCards.tsx`:
  - Grid of metric cards showing: Faithfulness, Relevance, Recall, Precision, Context Recall, Answer Relevance, Hallucination Rate, Toxicity Score, Bias Score
  - Each card: metric name, current value (gauge/progress), delta vs previous run, color-coded pass/fail
  - Agent filter dropdown at top
- [ ] Create `frontend/src/components/eval/TrendCharts.tsx`:
  - Line charts showing selected metrics over time (using a charting library — recharts or chart.js)
  - Multi-metric overlay support
  - Date range selector (7d, 30d, 90d)
  - Per-agent filtering
- [ ] Create `frontend/src/components/eval/RunHistory.tsx`:
  - Table of eval runs: run_id, agent, framework, status, total cases, pass rate, duration, date
  - Expandable row → per-case results with per-metric scores
  - Each metric shows score + reason (from DeepEval) + pass/fail badge
- [ ] Create `frontend/src/components/eval/RunConfigModal.tsx`:
  - "Run Evaluation" modal:
    - Select target agent
    - Select test suite
    - Choose framework: RAGAS / DeepEval / Both (radio buttons)
    - Checkboxes for individual metrics
    - Optional threshold overrides
    - "Run" button → triggers `POST /api/evalops/run`
  - Show run status polling after submission
- [ ] Update `EvalPanel.tsx` to compose all new components
- [ ] Add charting dependency if needed (recharts is lightweight, MIT-licensed)
- [ ] Add API methods: `getDashboardStats()`, `getDashboardTrends()`, `getRunMetrics()`

## Dependencies
- S5-01f (Dashboard stats/trends API)
- S5-01d (Enhanced run with framework selection)
