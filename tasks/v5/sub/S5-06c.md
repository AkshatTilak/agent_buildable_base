# S5-06c: APICallNode (Frontend + REST Executor Runtime)

> **Parent:** B5-06 (Workflow Builder Enhancements)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`, `projects/guardroute`

---

## Scope

REST API call node — supports all HTTP methods with auth and response mapping.

## Actionables

### Frontend
- [ ] Create `frontend/src/components/nodes/APICallNode.tsx`:
  - Rectangular node with API icon and HTTP verb color badge
  - Input handle, output handle
  - Display: method + URL summary
- [ ] PropertyDrawer config:
  - HTTP Method: GET, POST, PUT, PATCH, DELETE
  - URL (with `{{variable}}` interpolation)
  - Auth Type: None / Bearer Token / API Key Header
  - Auth value (token or key, masked input)
  - Headers: key-value editor
  - Request Body (for POST/PUT/PATCH): JSON editor with variable interpolation
  - Response Mapping: JSONPath expressions to extract specific fields from response
    - Map extracted fields to named outputs available to downstream nodes
  - Timeout + retry config

### Backend Runtime
- [ ] Create `projects/guardroute/src/nodes/api_call_executor.py`:
  - `async def execute_api_call(config: APICallConfig, state: GraphState) -> APICallResult`:
    - Interpolate variables in URL, headers, body
    - Apply auth (Bearer header or API key header)
    - Execute HTTP request via `httpx.AsyncClient`
    - SSRF protection (same as webhook — reuse utility)
    - Apply response mapping: extract fields via JSONPath (`jsonpath-ng` or manual traversal)
    - Return: `{status_code, mapped_outputs: dict, raw_response, execution_time_ms}`
  - Mapped outputs injected into graph state for downstream nodes
- [ ] Add test: `projects/guardroute/tests/test_api_call_executor.py`

## Dependencies
- S5-06b (Reuse SSRF protection utility)
