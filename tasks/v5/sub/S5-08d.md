## Scope

Build a pluggable retrieval strategy engine supporting Dense search, BM25 Sparse search, Hybrid Reciprocal Rank Fusion (RRF), and Neo4j Graph traversal.

## Actionables

- [x] Create `RetrievalEngine` class in `projects/syntraflow/src/retrieval/engine.py`
- [x] Implement strategy classes:
  - `DenseRetrievalStrategy`: Vector cosine similarity search
  - `SparseRetrievalStrategy`: BM25 keyword matching
  - `HybridRRFStrategy`: Combines Dense & Sparse results via RRF formula
  - `GraphRetrievalStrategy`: Neo4j Cypher entity neighborhood search
- [x] Expose unified API: `POST /api/syntraflow/query` with `strategy: "dense" | "sparse" | "hybrid" | "graph"`
- [x] Implement graceful fallback to `DenseRetrievalStrategy` if Neo4j graph database or Sparse indexes are offline or unconfigured
- [x] Add unit test: `projects/syntraflow/tests/test_retrieval_engine.py`
