# S5-02a: Agent Invocation Endpoint

> **Parent:** B5-02 (Agent Endpoints & Routing API)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `gateway`

---

## Scope

Create `gateway/api/agent_invoke.py` — the core endpoint for invoking any defined agent by its ID.

## Actionables

- [ ] Create `gateway/api/agent_invoke.py`:
  - `POST /api/agents/{agent_id}/invoke`:
    1. Query `AgentDefinition` from DB by `agent_id`
    2. Validate agent exists and `is_active == True`
    3. Build messages array: `[{role: "system", content: agent.system_prompt}, {role: "user", content: request.prompt}]`
    4. Optionally append conversation history if `session_id` provided
    5. Call `completion_with_fallback(model=agent.model_id, messages=messages, temperature=agent.temperature, max_tokens=agent.max_tokens, stream=is_streaming)`
    6. If agent has `tools` configured:
       - Resolve MCP tools from MCP registry
       - Run tool calling loop (function call → tool invoke → inject result → re-complete)
    7. Return: `{response, model_used, input_tokens, output_tokens, latency_ms, agent_id}`
  - SSE streaming support: check `Accept: text/event-stream` header, return `EventSourceResponse`
  - `POST /api/agents/{agent_id}/invoke/batch`:
    - Accept `{prompts: [str]}` array
    - Execute sequentially (or parallel with semaphore) — each prompt invoked against the agent
    - Return array of results
- [ ] Register router in `gateway/api/__init__.py`
- [ ] Add Pydantic models: `AgentInvokeRequest`, `AgentInvokeResponse`, `AgentBatchRequest`
- [ ] Add test: `gateway/tests/test_agent_invoke.py`

## Key Design Decisions

- Tool calling: If agent's `tools` list includes MCP tool names, resolve them via the MCP manager (B5-05). If MCP Hub not yet built, gracefully skip tool calls
- Batch endpoint caps at 20 prompts per request to prevent abuse
- Invocation logging is handled separately in S5-02c
