# S5-01c: Custom Dataset Manager (CRUD + Import/Export)

> **Parent:** B5-01 (EvalOps Deep Integration)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `projects/evalops`

---

## Scope

Create `projects/evalops/src/datasets/manager.py` and add CRUD API endpoints for managing test suites and individual test cases, plus bulk import/export.

## Actionables

- [ ] Create `projects/evalops/src/datasets/__init__.py`
- [ ] Create `projects/evalops/src/datasets/manager.py`:
  - `create_suite(db, agent_id, name, description) -> EvalTestSuite`
  - `list_suites(db, agent_id=None) -> List[EvalTestSuite]`
  - `update_suite(db, suite_id, name, description) -> EvalTestSuite`
  - `delete_suite(db, suite_id)` — cascades to test cases
  - `add_test_case(db, suite_id, input_query, expected_output, expected_context) -> EvalTestCase`
  - `update_test_case(db, case_id, ...) -> EvalTestCase`
  - `delete_test_case(db, case_id)`
  - `import_cases_from_csv(db, suite_id, csv_file) -> int` (returns count)
  - `import_cases_from_json(db, suite_id, json_data) -> int`
  - `export_suite_to_json(db, suite_id) -> dict`
  - `clone_suite(db, suite_id, new_name) -> EvalTestSuite`
- [ ] Add API routes to `projects/evalops/api.py`:
  - `POST /api/evalops/suites` — create suite
  - `GET /api/evalops/suites` — list suites (optional `?agent_id=` filter)
  - `PUT /api/evalops/suites/{id}` — update suite metadata
  - `DELETE /api/evalops/suites/{id}` — delete suite + cases
  - `POST /api/evalops/suites/{id}/cases` — add single case
  - `PUT /api/evalops/cases/{id}` — edit case
  - `DELETE /api/evalops/cases/{id}` — delete case
  - `POST /api/evalops/suites/{id}/import` — accept multipart CSV or JSON body
  - `GET /api/evalops/suites/{id}/export` — return JSON
  - `POST /api/evalops/suites/{id}/clone` — clone suite
- [ ] CSV format: columns `input_query,expected_output,expected_context` (context is semicolon-delimited for multiple chunks)
- [ ] JSON format: `[{"input_query": "...", "expected_output": "...", "expected_context": ["...", "..."]}]`
- [ ] Add test: `projects/evalops/tests/test_dataset_manager.py`
