  - `add_test_case`, `update_test_case`, `delete_test_case`, `list_test_cases`
  - `import_cases_from_csv`, `import_cases_from_json`, `export_suite_to_json`
- [x] Add API routes to `projects/evalops/api.py`:
  - `POST /api/evalops/suites` — create suite
  - `GET /api/evalops/suites` — list suites
  - `PUT /api/evalops/suites/{id}` — update suite metadata
  - `DELETE /api/evalops/suites/{id}` — delete suite
  - `POST /api/evalops/suites/{id}/clone` — clone suite
  - `POST /api/evalops/suites/{id}/cases` — add case
  - `PUT /api/evalops/cases/{id}` — edit case
  - `DELETE /api/evalops/cases/{id}` — delete case
  - `POST /api/evalops/suites/{id}/import` — accept multipart CSV or JSON body
  - `GET /api/evalops/suites/{id}/export` — return JSON
- [x] CSV format: columns `input_query,expected_output,expected_context`
- [x] JSON format: `[{"input_query": "...", "expected_output": "...", "expected_context": ["..."]}]`
