# S5-02c: Agent Invocation Logging

> **Parent:** B5-02 (Agent Endpoints & Routing API)  
> **Status:** `[x]`  
> **Complexity:** 🟢 Low  
> **Owner:** `gateway`, `common/models`

---

## Scope

Log every agent invocation to a dedicated table for analytics and create a stats query endpoint.

## Actionables

- [ ] Add `AgentInvocationLog` model to `common/models/database.py`:
  ```python
  class AgentInvocationLog(Base):
      __tablename__ = "agent_invocation_log"
      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      agent_id = Column(String(36), ForeignKey("agent_definitions.id", ondelete="CASCADE"), nullable=False, index=True)
      user_id = Column(String(36), ForeignKey("users.id", ondelete="SET NULL"), nullable=True, index=True)
      prompt = Column(Text, nullable=False)
      response = Column(Text, nullable=True)
      model_used = Column(String(200), nullable=True)
      input_tokens = Column(Integer, nullable=True)
      output_tokens = Column(Integer, nullable=True)
      latency_ms = Column(Float, nullable=True)
      status = Column(String(20), default="success")  # success / error / timeout
      route_decision = Column(String(50), nullable=True)  # direct / auto / round_robin
      metadata_json = Column(JSON, nullable=True)
      created_at = Column(DateTime, default=datetime.utcnow)
  ```
- [ ] Add logging call in `agent_invoke.py` after each invocation (both direct and routed)
- [ ] Add `GET /api/agents/{agent_id}/stats`:
  - Total invocations, avg latency, last used timestamp
  - Breakdown by status (success/error/timeout)
  - Token usage totals
  - Time-series: invocations per hour/day
- [ ] Generate Alembic migration
- [ ] Add test: `gateway/tests/test_invocation_logging.py`

## Key Design Decisions

- `user_id` is nullable (populated only when auth is enabled)
- Logging is fire-and-forget (background task) to not impact response latency
- PII in prompts should be scrubbed before logging (reuse GuardRoute's `scrub_pii`)
