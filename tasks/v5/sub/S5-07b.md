## Scope

Add OpenAI-compatible embedding and model listing endpoints.

## Actionables

- [x] `POST /v1/embeddings` in `gateway/api/external.py`:
  - Request: `{input: string | string[], model?: string}`
  - Default model: active embedding model from registry
  - Route to inference server's `/infer/embed` endpoint
  - Response format (OpenAI-compatible):
    ```json
    {
      "object": "list",
      "data": [{"object": "embedding", "embedding": [0.1, ...], "index": 0}],
      "model": "jinaai/jina-clip-v2",
      "usage": {"prompt_tokens": 5, "total_tokens": 5}
    }
    ```
- [x] `GET /v1/models` in `gateway/api/external.py`:
  - List all available models from registry + all active agent endpoint_slugs
  - Response format (OpenAI-compatible):
    ```json
    {
      "object": "list",
      "data": [
        {"id": "gemini/gemini-3.5-flash", "object": "model", "owned_by": "google", "created": 0},
        {"id": "my-research-agent", "object": "model", "owned_by": "contained", "created": 0}
      ]
    }
    ```
  - Agent slugs appear as models with `owned_by: "contained"`
