# S5-01d: Enhanced Eval Run Orchestration

> **Parent:** B5-01 (EvalOps Deep Integration)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `projects/evalops`

---

## Scope

Enhance the eval run pipeline (`runner/consumer.py`) to support framework selection (RAGAS/DeepEval/both), metric subset selection, and write granular per-metric results to the `eval_metric_results` table.

## Actionables

- [x] Modify `EvalRunRequest` Pydantic model in `api.py`:
  - `framework: Optional[str] = "both"` — `ragas`, `deepeval`, `both`
  - `metrics: Optional[List[str]] = None`
  - `thresholds: Optional[Dict[str, float]] = None`
- [x] Modify `POST /api/evalops/run` to pass framework/metrics/thresholds to runner
- [x] Modify `projects/evalops/src/runner/consumer.py` → `process_agent_eval_run()`:
  - Invokes target agent
  - Executes RAGAS / DeepEval evaluation metrics
  - Writes per-case, per-metric results to `eval_metric_results` table
  - Computes aggregate scores → updates `EvalRunHistory` row
- [x] Add `GET /api/evalops/runs/detail/{run_id}/metrics` — query `eval_metric_results` for a run
- [x] Add test: `projects/evalops/tests/test_eval_orchestration.py`

## Dependencies
- S5-01a (RAGAS runner)
- S5-01b (DeepEval runner)
