# S5-03b: Google OAuth Provider

> **Parent:** B5-03 (User Authentication & RBAC)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `gateway`

---

## Scope

Implement Google OAuth2 login flow using `authlib`.

## Actionables

- [ ] Add `authlib` to project dependencies (`pyproject.toml`)
- [ ] Implement in `gateway/auth/providers.py`:
  - `google_oauth = OAuth()` instance configured with `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
  - Google server metadata URL: `https://accounts.google.com/.well-known/openid-configuration`
  - Scopes: `openid email profile`
- [ ] Implement routes in `gateway/auth/routes.py`:
  - `GET /auth/login/google`:
    - Generate state token, store in session/cookie
    - Redirect to Google's authorization URL
  - `GET /auth/callback/google`:
    - Exchange authorization code for tokens
    - Fetch user info (email, name, picture, Google sub ID)
    - Upsert `User` record (create if new, update `last_login` if existing)
    - First user auto-assigned `admin` role; subsequent users get `viewer`
    - Create JWT via `create_access_token()`
    - Create `UserSession` record with token hash
    - Redirect to frontend with JWT in query param (frontend stores in localStorage)
- [ ] Handle edge cases:
  - User deactivated (`is_active=False`) → reject login
  - Invalid state token → reject callback
  - Google API errors → redirect to `/login?error=google_failed`
- [ ] Add test: `gateway/tests/test_google_oauth.py` (mock authlib)
