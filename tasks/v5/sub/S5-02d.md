# S5-02d: Agent CRUD Enhancements

> **Parent:** B5-02 (Agent Endpoints & Routing API)  
> **Status:** `[ ]`  
> **Complexity:** 🟢 Low  
> **Owner:** `gateway`, `common/models`

---

## Scope

Extend the existing Agent CRUD with activation toggle, auto-generated endpoint slugs, and stats surfacing.

## Actionables

- [ ] Add columns to `AgentDefinition` in `common/models/database.py`:
  - `is_active = Column(Boolean, default=True, index=True)` — enable/disable without deleting
  - `endpoint_slug = Column(String(100), unique=True, nullable=True)` — auto-generated from name (lowercase, hyphens)
- [ ] Modify `create_agent()` in `gateway/api/agent_crud.py`:
  - Auto-generate `endpoint_slug` from `name`: lowercase, replace spaces with hyphens, strip special chars
  - Ensure uniqueness (append `-2`, `-3` etc. if collision)
- [ ] Add `PATCH /api/agents/{agent_id}/toggle` — flip `is_active`
- [ ] Modify `list_agents()` — include `is_active`, `endpoint_slug` in response
- [ ] Update `AgentResponse` schema to include new fields
- [ ] Generate Alembic migration for new columns
- [ ] Add test: `gateway/tests/test_agent_crud_v5.py`

## Key Design Decisions

- `endpoint_slug` enables friendly URLs: `POST /v1/chat/completions` with `model: "my-research-agent"` instead of UUID
- Inactive agents return 403 when invoked
