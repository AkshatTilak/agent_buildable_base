## Scope

Extend the existing Agent CRUD with activation toggle, auto-generated endpoint slugs, and stats surfacing.

## Actionables

- [x] Add columns to `AgentDefinition` in `common/models/database.py`:
  - `is_active = Column(Boolean, default=True, index=True)` — enable/disable without deleting
  - `endpoint_slug = Column(String(100), unique=True, nullable=True)` — auto-generated from name (lowercase, hyphens)
- [x] Modify `create_agent()` in `gateway/api/agent_crud.py`:
  - Auto-generate `endpoint_slug` from `name`: lowercase, replace spaces with hyphens, strip special chars
  - Ensure uniqueness (append `-2`, `-3` etc. if collision)
- [x] Add `PATCH /api/agents/{agent_id}/toggle` — flip `is_active`
- [x] Modify `list_agents()` — include `is_active`, `endpoint_slug` in response
- [x] Update `AgentResponse` schema to include new fields
- [x] Generate Alembic migration for new columns
- [x] Add test: `tests/test_agent_crud_v5.py`

## Key Design Decisions

- `endpoint_slug` enables friendly URLs: `POST /api/agents/my-research-agent/invoke` instead of UUID
- Inactive agents return 403 when invoked
