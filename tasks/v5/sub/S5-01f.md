# S5-01f: EvalOps Dashboard Stats & Trends API

> **Parent:** B5-01 (EvalOps Deep Integration)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `projects/evalops`

---

## Scope

Add API endpoints that serve aggregated evaluation statistics and time-series trend data for the frontend dashboard.

## Actionables

- [ ] Add `GET /api/evalops/dashboard/stats` to `api.py`:
  - Query latest `EvalRunHistory` per agent
  - Return aggregated: avg faithfulness, avg relevance, avg recall, avg precision, avg context_recall, avg answer_relevance, avg hallucination, avg toxicity, avg bias
  - Group by agent_id
  - Include total runs, total test cases, overall pass rate
- [ ] Add `GET /api/evalops/dashboard/trends` to `api.py`:
  - Accept `?agent_id=&metric=&days=30`
  - Query `EvalRunHistory` for the specified agent over the time range
  - Return time-series: `[{date, metric_value}]` for charting
  - Support multiple metrics in single request: `?metrics=faithfulness,toxicity`
- [ ] Add `GET /api/evalops/dashboard/comparison` to `api.py`:
  - Compare metrics across agents side-by-side
  - Return: `{agent_id: {metric: avg_score}}` for all agents
- [ ] Optimize queries with proper indexing (created_at, agent_id)
- [ ] Add test: `projects/evalops/tests/test_dashboard_api.py`
