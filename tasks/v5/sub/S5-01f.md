## Scope

Add API endpoints that serve aggregated evaluation statistics and time-series trend data for the frontend dashboard.

## Actionables

- [x] Add `GET /api/evalops/dashboard/stats` to `api.py`:
  - Query `EvalRunHistory`
  - Return aggregated mean scores: faithfulness, relevance, recall, precision, context_recall, answer_relevance, hallucination, toxicity, bias
  - Filter by agent_id
  - Include total runs, total test cases, overall pass rate
- [x] Add `GET /api/evalops/dashboard/trends` to `api.py`:
  - Query time-series `EvalRunHistory` for specified time window (`days=30`)
- [x] Add `GET /api/evalops/dashboard/comparison` to `api.py`:
  - Compare metrics across agents side-by-side
- [x] Add test: `projects/evalops/tests/test_dashboard_api.py`
