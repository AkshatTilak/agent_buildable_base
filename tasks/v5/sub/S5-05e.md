## Scope

Create the MCP Hub management page in the frontend.

## Actionables

- [ ] Create `frontend/src/components/MCPHubPage.tsx`:
  - **Server List Panel**: cards for each registered MCP server:
    - Name, URL, transport badge, auth type badge
    - Health status indicator (green dot = healthy, yellow = checking, red = unhealthy)
    - "Internal" badge for auto-registered servers
    - Toggle active/inactive
    - Actions: Edit, Delete (blocked for internal), Sync Tools, Health Check
  - **"Add External Server" button** → modal:
    - Name, URL, Transport dropdown (SSE/stdio/Streamable HTTP), Auth (None/Bearer/API Key), Token field
    - "Test Connection" button before saving
  - **Tool List** (expandable per server):
    - Tool name, description, input schema (collapsible JSON display)
    - Enable/disable toggle per tool
  - **Tool Test Panel** (inline or slide-out):
    - Select a tool → auto-generate input form from `input_schema_json`
    - "Test" button → invoke and display result
    - Show execution time
- [ ] Add route `/mcp` in `App.tsx`
- [ ] Add "MCP Hub" entry in `Sidebar.tsx` navigation (new icon)
- [ ] Add API service methods: `listMCPServers()`, `addMCPServer()`, `updateMCPServer()`, `deleteMCPServer()`, `discoverTools()`, `listAllTools()`, `invokeTool()`, `testTool()`
- [ ] TypeScript types: `MCPServer`, `MCPTool`, `MCPTestResult`
