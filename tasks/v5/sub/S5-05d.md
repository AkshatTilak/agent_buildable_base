# S5-05d: Internal MCP Auto-Registration

> **Parent:** B5-05 (MCP Integration Hub)  
> **Status:** `[ ]`  
> **Complexity:** 🟢 Low  
> **Owner:** `gateway`, `projects/syntraflow`

---

## Scope

Auto-register SyntraFlow's existing MCP server as an internal entry on gateway startup.

## Actionables

- [ ] Modify `gateway/core/setup.py` lifespan hook:
  - After all project setup hooks complete, check if SyntraFlow MCP server is registered in `mcp_servers` table
  - If not, auto-insert: `{name: "SyntraFlow (Internal)", url: "http://localhost:8012", transport: "sse", is_internal: True, is_active: True}`
  - If already exists, update health status
- [ ] Trigger tool discovery for the internal server on startup
- [ ] Add `MCP_SYNTRAFLOW_URL` to settings (default: `http://localhost:8012`)
- [ ] Ensure internal servers cannot be deleted via API (add guard in delete endpoint)
- [ ] Future-proof: add a `register_mcp_server()` utility that any submodule's `setup.py` can call
