## Scope

Add API key management and documentation to the Settings page.

## Actionables

- [ ] Add "API Keys" tab to `SettingsPage.tsx`
- [ ] Create `frontend/src/components/settings/APIKeysPanel.tsx`:
  - "Generate New Key" button → modal:
    - Name input
    - Rate limit selector (requests/minute)
    - "Generate" → show full key **once** with copy button + warning "you won't see this again"
  - API keys table: prefix/masked display, name, created, last used, usage count, rate limit, active toggle
  - Actions: Edit name/rate limit, Revoke (with confirmation)
- [ ] Create `frontend/src/components/settings/APIDocsPanel.tsx`:
  - Quick-start guide with code examples:
    - Python (`openai` SDK):
      ```python
      from openai import OpenAI
      client = OpenAI(base_url="http://localhost:8000/v1", api_key="sk-...")
      response = client.chat.completions.create(model="my-agent", messages=[...])
      ```
    - cURL:
      ```bash
      curl http://localhost:8000/v1/chat/completions \
        -H "Authorization: Bearer sk-..." \
        -d '{"model":"gemini/gemini-3.5-flash","messages":[...]}'
      ```
    - JavaScript (`fetch`):
      ```js
      const res = await fetch("/v1/chat/completions", {
        method: "POST",
        headers: {"Authorization": "Bearer sk-...", "Content-Type": "application/json"},
        body: JSON.stringify({model: "my-agent", messages: [...]})
      });
      ```
  - Available models/agents list (from `/v1/models`)
  - Rate limit info
- [ ] Add API service methods: `generateAPIKey()`, `listAPIKeys()`, `updateAPIKey()`, `revokeAPIKey()`, `getKeyUsage()`
