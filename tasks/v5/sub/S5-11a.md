## Scope

Build reverse proxy router endpoints in FastAPI Gateway to securely forward requests to Qdrant UI (`localhost:6333`) and Neo4j Browser (`localhost:7474`).

## Actionables

- [x] Create `gateway/api/proxy.py` using `httpx` async client
- [x] Mount routes:
  - `ANY /qdrant/{path:path}` → proxy to `http://localhost:6333/{path}`
  - `ANY /neo4j/{path:path}` → proxy to `http://localhost:7474/{path}`
- [x] Strip restrictive framing response headers (`X-Frame-Options`, `Content-Security-Policy`) to enable iframe embedding in React UI
- [x] Handle subpath asset rewriting for static JS/CSS bundles requested by proxied dashboards
- [x] Add unit test: `gateway/tests/test_ui_proxy.py`
