# S5-04e: Frontend — File Attachment Zone & Session Sidebar

> **Parent:** B5-04 (Model Playground)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`

---

## Scope

Add file attachment capabilities and session management sidebar to PlaygroundPage.

## Actionables

- [ ] Create `frontend/src/components/playground/AttachmentZone.tsx`:
  - Drag-and-drop zone or click-to-browse button below the message input
  - Accepted types: PDF, PNG, JPG, WEBP, MP4, WEBM, TXT, MD, CSV
  - Upload progress indicator
  - After upload: show attachment chip with filename, icon, extracted text preview (expandable)
  - For images: show thumbnail preview
  - For PDFs: show page count + text snippet
  - For videos: show duration + transcription snippet
  - Remove attachment button (X)
  - Attached files are sent as `attachment_ids` with the chat request
- [ ] Create `frontend/src/components/playground/SessionSidebar.tsx`:
  - Collapsible left sidebar
  - "New Session" button at top
  - List of saved sessions: name, model, last updated, message count
  - Click to load session (restores messages, model, system prompt, params)
  - Session actions: Rename, Delete (with confirmation)
  - Auto-save current session on each message exchange
  - Search/filter sessions
- [ ] Add API service methods: `uploadFile()`, `listSessions()`, `saveSession()`, `loadSession()`, `deleteSession()`
- [ ] Wire attachment zone into PlaygroundPage layout
