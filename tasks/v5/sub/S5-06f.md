# S5-06f: Graph Parser V5 (Parse All New Node Types)

> **Parent:** B5-06 (Workflow Builder Enhancements)  
> **Status:** `[x]`  
> **Complexity:** 🔴 High  
> **Owner:** `projects/guardroute`

---

## Scope

Extend `projects/guardroute/src/core/graph_parser.py` to parse all 7 new V5 node types into executable LangGraph StateGraph nodes.

## Actionables

- [ ] Extend `GraphParser.validate_graph()` to recognize new node types:
  - `if_else`, `webhook`, `api_call`, `eval`, `mcp_tool`, `router`, `transform`
- [ ] Add node compilation methods:
  - **`_compile_if_else_node(node_data)`**: Create LangGraph `add_conditional_edges` from the classify output, routing to "true_branch" and "false_branch" targets based on condition config
  - **`_compile_webhook_node(node_data)`**: Create async node that calls `webhook_executor.execute_webhook()`
  - **`_compile_api_call_node(node_data)`**: Create async node that calls `api_call_executor.execute_api_call()`
  - **`_compile_eval_node(node_data)`**: Create node that calls `eval_executor.execute_eval_node()`, adds conditional edges for pass/fail handles
  - **`_compile_mcp_tool_node(node_data)`**: Create node that calls `mcp_tool_executor.execute_mcp_tool()`
  - **`_compile_router_node(node_data)`**: Create node with N-way conditional edges from `router_executor.evaluate_routes()`
  - **`_compile_transform_node(node_data)`**: Create node that calls `transform_executor.execute_transform()`
- [ ] Extend `GraphState` TypedDict to support new fields:
  - `webhook_results: Dict[str, Any]`
  - `api_call_results: Dict[str, Any]`
  - `eval_results: Dict[str, Any]`
  - `transform_outputs: Dict[str, Any]`
- [ ] Update cycle detection (Kahn's algorithm) to handle:
  - IfElse branching (two outgoing edges)
  - Router N-way branching (N outgoing edges)
  - EvalNode pass/fail branches
- [ ] Update validation to ensure:
  - Webhook/API nodes have valid URLs configured
  - MCP tool nodes reference existing tools
  - All branches eventually reach a terminal node (Synthesis/END)
- [ ] Add comprehensive test: `projects/guardroute/tests/test_graph_parser_v5.py`
  - Test each node type individually
  - Test complex graphs with mixed node types
  - Test cycle detection with branching nodes
  - Test validation error cases

## Dependencies
- S5-06a through S5-06e (All node executors must exist)
