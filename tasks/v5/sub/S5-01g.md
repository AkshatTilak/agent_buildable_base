# S5-01g: Frontend — Suite Manager Tab

> **Parent:** B5-01 (EvalOps Deep Integration)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`

---

## Scope

Add a "Test Suites" tab to the EvalPanel that allows CRUD management of test suites and individual test cases, plus CSV/JSON import/export.

## Actionables

- [ ] Add tab navigation to `EvalPanel.tsx`: "Dashboard" | "Test Suites" | "Run History"
- [ ] Create `frontend/src/components/eval/SuiteManager.tsx`:
  - List all test suites with agent name, case count, last updated
  - "Create Suite" button → modal with name, description, agent selection
  - Per-suite actions: Edit, Delete, Clone, Export (JSON), Import (CSV/JSON)
  - Expandable rows showing test cases within a suite
- [ ] Create `frontend/src/components/eval/TestCaseEditor.tsx`:
  - Inline editable rows for test cases: input_query, expected_output, expected_context
  - "Add Case" button for manual case creation
  - Delete individual cases
  - Validate required fields before save
- [ ] Create `frontend/src/components/eval/ImportModal.tsx`:
  - File upload zone (drag-drop) for CSV or JSON
  - Preview parsed cases before confirming import
  - Show import count + validation errors
- [ ] Add API service methods in `frontend/src/services/api.ts`:
  - `createSuite()`, `listSuites()`, `updateSuite()`, `deleteSuite()`
  - `addTestCase()`, `updateTestCase()`, `deleteTestCase()`
  - `importCases()`, `exportSuite()`, `cloneSuite()`
- [ ] Wire all components with loading states, error handling, toast notifications

## Dependencies
- S5-01c (Backend CRUD + import/export endpoints)
