# S5-06g: Dynamic Node Palette

> **Parent:** B5-06 (Workflow Builder Enhancements)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`

---

## Scope

Enhance the WorkflowCanvas node palette to auto-populate from platform data (agents, MCP tools, eval suites) and organize nodes into categorized sections.

## Actionables

- [ ] Modify `WorkflowCanvas.tsx` — add/refactor node palette sidebar:
  - **Categorized sections** (collapsible):
    - **Core**: ClassifierNode, SynthesisNode, RetrievalNode
    - **Agents**: Dynamically list all active agents from AgentHub → each as a draggable AgentNode pre-configured with that agent's ID/model
    - **Logic**: IfElseNode, RouterNode, TransformNode
    - **Integrations**: WebhookNode, APICallNode
    - **Evaluation**: EvalNode (with suite quick-select)
    - **Tools**: Dynamically list all enabled MCP tools → each as a draggable MCPToolNode pre-configured with server_id + tool_name
  - Search/filter bar at top of palette
  - Drag from palette → drop onto canvas to create node
- [ ] Create API endpoint or reuse existing:
  - `GET /api/workflow/palette` — returns categorized node list:
    - Core nodes (static list)
    - Active agents (from `GET /api/agents`)
    - MCP tools (from `GET /api/mcp/tools`)
    - Eval suites (from `GET /api/evalops/suites`)
- [ ] When new agents/tools/suites are added elsewhere, palette refreshes automatically (poll or WebSocket)
- [ ] Each palette item shows: icon, name, description tooltip, category badge
- [ ] Add visual distinction for each category: color-coded node borders
- [ ] Add test: verify palette populates correctly with mock data

## Dependencies
- B5-02 (Agents list)
- B5-05 (MCP tools list)
- B5-01 (Eval suites list)
- S5-06a through S5-06e (All new node components)
