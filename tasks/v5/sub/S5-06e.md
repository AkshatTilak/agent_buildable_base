# S5-06e: RouterNode & TransformNode (Frontend + Runtime)

> **Parent:** B5-06 (Workflow Builder Enhancements)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`, `projects/guardroute`

---

## Scope

Two utility workflow nodes: multi-branch routing and data transformation.

## Actionables

### RouterNode

#### Frontend
- [ ] Create `frontend/src/components/nodes/RouterNode.tsx`:
  - Hexagonal or wide rectangular node with routing icon
  - One input handle, N dynamic output handles (one per route)
  - Display: route count, default route label
- [ ] PropertyDrawer:
  - Route table: rows of `[condition, target_label]`
  - Default route (fallback when no condition matches)
  - Each condition uses same format as IfElseNode conditions
  - "Add Route" button to add more branches
  - Each route gets a named output handle on the node

#### Backend
- [ ] Create `projects/guardroute/src/nodes/router_executor.py`:
  - `evaluate_routes(routes: List[RouteConfig], state: GraphState) -> str`:
    - Iterate routes in order, evaluate each condition
    - Return label of first matching route
    - If none match → return default route label
  - Reuses `conditional_evaluator` from S5-06a

### TransformNode

#### Frontend
- [ ] Create `frontend/src/components/nodes/TransformNode.tsx`:
  - Rectangular node with transform/gear icon
  - Input handle, output handle
  - Display: transform type summary
- [ ] PropertyDrawer:
  - Transform type: `template`, `extract_field`, `merge`, `format_json`
  - **Template mode**: Jinja2-style template editor with available variables
  - **Extract field**: JSONPath or dot-notation field path
  - **Merge mode**: combine outputs from multiple upstream nodes
  - **Format JSON**: restructure data with field mapping

#### Backend
- [ ] Create `projects/guardroute/src/nodes/transform_executor.py`:
  - `execute_transform(config: TransformConfig, state: GraphState) -> TransformResult`:
    - **Template**: render Jinja2 template with state vars (use `jinja2.sandbox.SandboxedEnvironment` for safety)
    - **Extract**: navigate state with dot path → return extracted value
    - **Merge**: combine specified state fields into single dict
    - **Format JSON**: apply field mapping to restructure data
  - Return: `{output: Any, output_type: str}`
- [ ] Add tests for both nodes
