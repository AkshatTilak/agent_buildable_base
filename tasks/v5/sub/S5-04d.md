## Actionables

- [ ] Create `frontend/src/components/PlaygroundPage.tsx`:
  - Two-panel layout: session sidebar (left, collapsible) + chat area (right)
  - Chat area components:
    - **System Prompt Panel** (collapsible top): textarea for system prompt, persists per session
    - **Model Selector**: dropdown populated from model registry (completion + classifier models)
    - **Parameter Controls**: temperature slider (0-2), max_tokens slider, top_p (optional)
    - **Message List**: scrollable message bubbles (user=right, assistant=left)
    - **Input Area**: multi-line text input, "Send" button, keyboard shortcut (Ctrl+Enter)
  - Per-message features:
    - Token count badge
    - Copy to clipboard button
    - "Regenerate" button (re-sends same prompt)
    - "Edit & Resend" (click to edit previous user message, re-send)
  - Streaming: tokens append character-by-character with typing animation
  - Auto-scroll to bottom on new messages

- [ ] Style with platform design tokens: dark theme, message bubbles with glassmorphism
