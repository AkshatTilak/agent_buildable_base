# S5-05c: Tool Invocation API & Testing

> **Parent:** B5-05 (MCP Integration Hub)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `gateway`

---

## Scope

Enable invoking any registered MCP tool by name with parameters, including inline testing.

## Actionables

- [ ] Add to `gateway/services/mcp_client.py`:
  - `invoke_tool(server: MCPServer, tool_name: str, params: dict) -> dict`:
    - Connect to MCP server
    - Call tool with provided parameters
    - Return result (text/json)
    - Timeout: 30 seconds (configurable)
- [ ] Add API endpoints in `mcp_manager.py`:
  - `POST /api/mcp/tools/invoke`:
    - Body: `{server_id, tool_name, parameters: {}}`
    - Resolve server from DB, validate tool exists in cache
    - Invoke via `mcp_client.invoke_tool()`
    - Return: `{result, execution_time_ms, status}`
  - `POST /api/mcp/servers/{id}/tools/{tool_name}/test`:
    - Same as invoke but explicitly labeled for testing
    - Accepts sample input, returns result + timing
- [ ] Error handling:
  - Server unreachable → 503 with helpful message
  - Tool not found → 404
  - Tool execution error → 500 with error details from MCP
  - Timeout → 504
- [ ] Add test: `gateway/tests/test_mcp_invoke.py`

## Dependencies
- S5-05a (Server registry)
- S5-05b (Tool cache for validation)
