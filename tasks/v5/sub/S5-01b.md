# S5-01b: DeepEval Evaluation Runner

> **Parent:** B5-01 (EvalOps Deep Integration)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `projects/evalops`

---

## Scope

Create `projects/evalops/src/metrics/deepeval_runner.py` — runs DeepEval metrics against agent responses.

## Actionables

- [ ] Create `projects/evalops/src/metrics/deepeval_runner.py`:
  - Import from `deepeval.metrics`: `HallucinationMetric`, `ToxicityMetric`, `BiasMetric`, `AnswerRelevancyMetric`, `FaithfulnessMetric`
  - Import `deepeval.test_case.LLMTestCase`, `deepeval.evaluate`
  - Configure judge model: set `DEEPEVAL_MODEL` env var to platform's LiteLLM model ID (e.g., `gemini/gemini-3.5-flash`) — NOT OpenAI default
  - Function: `async def run_deepeval_evaluation(test_cases: List[EvalTestCase], agent_responses: List[str], retrieved_contexts: List[List[str]], metrics: List[str] = None) -> DeepEvalResult`
  - If `metrics` param provided, only run those specific metrics (subset selection)
  - `DeepEvalResult` contains per-case per-metric scores + reasons + aggregate
- [ ] Create schemas: `DeepEvalResult`, `DeepEvalCaseResult`, `DeepEvalMetricScore` in `projects/evalops/src/metrics/schemas.py`
- [ ] Handle each metric independently — if one metric fails, others still compute
- [ ] Add test: `projects/evalops/tests/test_deepeval_runner.py`

## Key Design Decisions

- DeepEval's `evaluate()` is synchronous — wrap in `asyncio.to_thread()`
- Each metric has a `threshold` param — expose configurable thresholds in the API
- DeepEval stores `.deepeval` cache dir — ensure this doesn't conflict with project root `.deepeval`
