# S5-07a: OpenAI-Compatible Chat Completions Endpoint

> **Parent:** B5-07 (External API Gateway)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `gateway`

---

## Scope

Create `gateway/api/external.py` with an OpenAI-compatible `/v1/chat/completions` endpoint.

## Actionables

- [x] Create `gateway/api/external.py`
- [x] `POST /v1/chat/completions`:
  - Request format (OpenAI-compatible):
    ```json
    {
      "model": "gemini/gemini-3.5-flash",  // or agent endpoint_slug
      "messages": [{"role": "user", "content": "Hello"}],
      "temperature": 0.7,
      "max_tokens": 2048,
      "stream": false
    }
    ```
  - Routing logic:
    1. Check if `model` matches an agent `endpoint_slug` → invoke agent (S5-02a logic)
    2. Check if `model` matches a `model_id` in registry → direct `completion_with_fallback()`
    3. If neither matches → return 404 with available models list
  - Response format (OpenAI-compatible):
    ```json
    {
      "id": "chatcmpl-...",
      "object": "chat.completion",
      "created": 1234567890,
      "model": "gemini/gemini-3.5-flash",
      "choices": [{"index": 0, "message": {"role": "assistant", "content": "..."}, "finish_reason": "stop"}],
      "usage": {"prompt_tokens": 10, "completion_tokens": 50, "total_tokens": 60}
    }
    ```
  - Streaming format (OpenAI SSE):
    ```
    data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"delta":{"content":"token"},"index":0}]}
    ```
- [x] Pydantic models: `ChatCompletionRequest`, `ChatCompletionResponse`, `ChatCompletionChunk`
- [x] Register router with prefix `/v1`
- [x] Add test: `gateway/tests/test_external_api.py`

## Key Design Decisions

- Full OpenAI SDK compatibility: users can point `openai.OpenAI(base_url="http://localhost:8000/v1")` at ContAIned
- Agent slugs are valid `model` values, enabling: `client.chat.completions.create(model="my-research-agent")`
