# S5-03e: Frontend — Login Page & Auth State Management

> **Parent:** B5-03 (User Authentication & RBAC)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend`

---

## Scope

Create the login page and integrate auth state management into the Zustand store.

## Actionables

- [ ] Create `frontend/src/components/auth/LoginPage.tsx`:
  - Clean, centered login card (dark theme matching platform design)
  - ContAIned logo/branding at top
  - "Sign in with Google" button (Google brand colors/icon)
  - "Sign in with GitHub" button (GitHub brand colors/icon)
  - Buttons redirect to `/auth/login/google` and `/auth/login/github` respectively
  - Error message display (from URL query param `?error=...`)
- [ ] Create `frontend/src/components/auth/AuthCallback.tsx`:
  - Route: `/auth/callback`
  - Reads JWT from URL query params
  - Stores JWT in localStorage
  - Fetches user info via `GET /auth/me`
  - Redirects to `/system` (dashboard home)
- [ ] Extend `frontend/src/store/useStore.ts`:
  - Add auth slice: `user`, `token`, `isAuthenticated`, `isAuthEnabled`
  - Actions: `setUser()`, `setToken()`, `logout()`, `checkAuth()`
  - On app init: check localStorage for token, validate via `/auth/me`, set auth state
  - `isAuthEnabled` fetched from backend health endpoint
- [ ] Add API service methods in `api.ts`:
  - `getMe()` — `GET /auth/me`
  - `logout()` — `POST /auth/logout`
- [ ] Add route `/login` in `App.tsx`
- [ ] Style login page with premium glassmorphism, subtle animations

## Dependencies
- S5-03b/S5-03c (Backend OAuth endpoints)
- S5-03d (Backend `/auth/me` endpoint)
