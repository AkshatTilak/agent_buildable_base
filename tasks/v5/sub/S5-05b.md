# S5-05b: Tool Discovery & Caching

> **Parent:** B5-05 (MCP Integration Hub)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `gateway`

---

## Scope

Discover available tools from registered MCP servers and cache their schemas.

## Actionables

- [ ] Add `MCPToolCache` model to `common/models/database.py`:
  ```python
  class MCPToolCache(Base):
      __tablename__ = "mcp_tool_cache"
      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      server_id = Column(String(36), ForeignKey("mcp_servers.id", ondelete="CASCADE"), nullable=False, index=True)
      tool_name = Column(String(200), nullable=False)
      description = Column(Text, nullable=True)
      input_schema_json = Column(JSON, nullable=True)
      is_enabled = Column(Boolean, default=True)
      last_synced = Column(DateTime, default=datetime.utcnow)
  ```
- [ ] Create `gateway/services/mcp_client.py`:
  - `discover_tools(server: MCPServer) -> List[MCPToolInfo]`:
    - For SSE transport: connect to MCP server, call `list_tools()`
    - Parse tool names, descriptions, input schemas
    - Return structured list
  - Use `mcp` Python library's client capabilities
- [ ] Add API endpoints in `mcp_manager.py`:
  - `GET /api/mcp/servers/{id}/tools` — discover & sync tools from server, update cache
  - `GET /api/mcp/tools` — aggregated list of all cached tools across all servers
  - `PUT /api/mcp/tools/{id}/toggle` — enable/disable a tool
- [ ] Auto-sync: when a server is registered or health check passes, auto-discover tools
- [ ] Generate Alembic migration
- [ ] Add test: `gateway/tests/test_mcp_discovery.py`

## Dependencies
