## Scope

Build `projects/syntraflow/src/collections/manager.py` and API endpoints for dynamic Qdrant collection lifecycle management.

## Actionables

- [ ] Create `CollectionManager` class wrapping Qdrant client collection initialization and deletion
- [ ] Implement REST endpoints in `projects/syntraflow/api.py`:
  - `POST /api/syntraflow/collections`: Create new vector collection in Qdrant and register in SQL
  - `GET /api/syntraflow/collections`: List collections with document counts and vector stats
  - `GET /api/syntraflow/collections/{id}`: Get detailed collection info
  - `DELETE /api/syntraflow/collections/{id}`: Delete collection and purge vectors
- [ ] Add unit test: `projects/syntraflow/tests/test_collection_api.py`
