# S6-12b: Shared Component Layer & `DataTable`

> **Parent:** B6-12 (UX, Interaction & Accessibility Uplift)  
> **Status:** `[ ]`  
> **Complexity:** 🔴 High  
> **Owner:** `frontend/src`

---

## Scope

Build the shared component layer that every V6 surface consumes, centred on a real `DataTable`. Today
[frontend/src/components/shared](frontend/src/components/shared) offers only `ConfirmModal`,
`EmptyState`, `ErrorBanner`, `ErrorBoundary`, `LoadingSkeleton`, `StatusBadge` and `ToastProvider`, and
every list surface hand-rolls its own `<table>`, header block and drawer. V6 adds far more list surfaces
(workflows, runs, suites, cases, users, invites, audit, documents, collections), so the duplication must
be collapsed before those land.

Boundary: this subtask builds and adopts the components. State-content standardisation (skeleton
shapes, error copy, error-code map) is S6-12c; accessibility hardening is S6-12d.

## Actionables

- [ ] Build `frontend/src/components/shared/DataTable.tsx` as a generic `DataTable<T>` with a declarative `columns: Column<T>[]` API (`key`, `header`, `render`, `sortable`, `width`, `minWidth`, `align`, `sticky`):
  - [ ] Client and server sorting via `sort: { key, dir }` + `onSortChange`, with a visible sort indicator on the active column.
  - [ ] Column resizing by drag with persisted widths per table id in `localStorage`, honouring `minWidth`.
  - [ ] Sticky header (and optional sticky first column) that stays pinned under the shared `PageHeader`.
  - [ ] Row selection: `selectable`, `selectedIds`, `onSelectionChange`, header checkbox with indeterminate state, `Shift+click` range selection.
  - [ ] A `BulkActionBar` slot that appears when `selectedIds.length > 0`, showing the count, the actions and a Clear control.
  - [ ] Pagination footer supporting both offset and cursor modes, with page size 25/50/100 and a total/range readout.
  - [ ] Keyboard navigation: `↑`/`↓` move the focused row, `Enter` triggers `onRowActivate`, `Space` toggles selection, `Home`/`End` jump, and focus is preserved across re-renders.
  - [ ] `rowKey`, `loading`, `error`, `emptyState` props delegating to the shared state components rather than rendering inline markup.
  - [ ] An optional `virtualise` prop hooking the virtualisation strategy from S6-12f.
- [ ] Build `frontend/src/components/shared/PageHeader.tsx`: title, optional breadcrumb slot, description line, status chips slot, and a right-aligned primary/secondary action slot; consistent spacing from the V4 tokens.
- [ ] Build `frontend/src/components/shared/Drawer.tsx`: right-anchored, sizes `sm | md | lg`, header with title + close, scrollable body, sticky footer action row, scrim from `--overlay-scrim`, and an `onClose` fired by scrim click and `Esc`.
- [ ] Build `frontend/src/components/shared/Tabs.tsx` with roving-tabindex arrow-key navigation and URL-synced active tab via a `queryKey` prop.
- [ ] Build `frontend/src/components/shared/Chip.tsx` (variants `status | hub | tag | count`, resolving colour from the S6-12a tokens and always pairing colour with a label) and fold [frontend/src/components/shared/StatusBadge.tsx](frontend/src/components/shared/StatusBadge.tsx) into it.
- [ ] Build `frontend/src/components/shared/Tooltip.tsx` (hover + focus triggered, `Esc` dismiss, 400 ms open delay, portal-rendered so it escapes table overflow) and `frontend/src/components/shared/CopyButton.tsx` (copies a value, announces "Copied" in a live region, reverts after 2 s, never logs the copied value).
- [ ] Extend [frontend/src/components/shared/ConfirmModal.tsx](frontend/src/components/shared/ConfirmModal.tsx) with a `variant="destructive"` requiring the user to type the exact resource name before the confirm button enables, showing the expected string and a mismatch hint.
- [ ] Export everything from [frontend/src/components/shared/index.ts](frontend/src/components/shared/index.ts) and document each component's props in a short `frontend/src/components/shared/README.md` so hub surfaces do not re-invent them.
- [ ] Migrate every V6 list surface onto `DataTable`: `WorkflowLibrary`, `WorkflowRuns`, `SuiteManager`, `CaseResultsTable`, `UserDirectory`, `InviteManager`, `AuditLogViewer`, hub member lists, hub link lists, collection and document lists.
  - [ ] Proof: `grep -rn "<table" frontend/src/components | grep -v shared/DataTable` → 0 hits.
- [ ] Delete the ad-hoc duplicates the shared layer replaces (local header blocks, per-page pagination controls, bespoke drawers/modals, one-off badge components) and fix the resulting imports.
- [ ] Add component tests for `DataTable`: sorting toggles direction, `Shift+click` selects a range, resizing persists a width, keyboard row navigation moves focus, and the bulk bar appears/clears correctly.
