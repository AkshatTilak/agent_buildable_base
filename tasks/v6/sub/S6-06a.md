# S6-06a: Workflow, Version & Run Models + Migration

> **Parent:** B6-06 (Workflow Hub — Multi-Workflow Management & Versioning)  
> **Status:** `[ ]`  
> **Complexity:** 🔴 High  
> **Owner:** `common/models`, `migrations`  

---

## Scope

Land the V6 workflow persistence layer exactly as specified in
[`workflow_v6.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/workflow_v6.md)
§2.1–2.3. The V5 `WorkflowDefinition` model in
[`common/models/database.py`](file:///c:/Akshat/ContAIned/common/models/database.py) — which holds
`graph_json` inline and models "active workflow" as a singleton boolean — is replaced by a hub-scoped
`workflows` table plus two new tables: immutable `workflow_versions` holding the graph snapshots, and
`workflow_runs` holding execution history.

`eval_flow_traces` is extended so per-node execution detail from a workflow run is written to the same
table the Eval Hub already reads, linked by `run_id → workflow_runs.id`. The Alembic revision backfills
every existing workflow into a published v1 version so no graph is lost.

## Actionables

- [ ] Rewrite `WorkflowDefinition` (table `workflows`) in [`common/models/database.py`](file:///c:/Akshat/ContAIned/common/models/database.py) to match §2.1 exactly:
  ```python
  class WorkflowDefinition(Base):
      __tablename__ = "workflows"
      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      hub_id = Column(String(36), ForeignKey("hubs.id", ondelete="CASCADE"), nullable=False, index=True)
      name = Column(String(120), nullable=False)
      slug = Column(String(120), nullable=False)
      description = Column(Text, nullable=True)
      tags_json = Column(JSON, nullable=False, default=list)
      status = Column(String(20), nullable=False, default="draft")   # draft | published | archived
      published_version_id = Column(String(36), ForeignKey("workflow_versions.id", ondelete="SET NULL"), nullable=True)
      draft_version_id = Column(String(36), ForeignKey("workflow_versions.id", ondelete="SET NULL"), nullable=True)
      created_by = Column(String(36), ForeignKey("users.id", ondelete="SET NULL"), nullable=True)
      created_at = Column(DateTime, default=datetime.utcnow)
      updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
      __table_args__ = (UniqueConstraint("hub_id", "slug", name="uq_workflows_hub_slug"),)
  ```
  Drop `graph_json` and `is_active` from this model. Use `use_alter=True` on the two version FKs to break the circular dependency with `workflow_versions.workflow_id`.
- [ ] Add `WorkflowVersion` (table `workflow_versions`) per §2.2 with `version_number` (Integer, monotonic per workflow, starts at 1), `graph_json` (JSON, `nullable=False`), `change_note` (String(255)), `is_valid` (Boolean, default `False`), `validation_json` (JSON, nullable), `created_by`, `created_at`, and `UniqueConstraint("workflow_id", "version_number", name="uq_workflow_versions_number")`.
- [ ] Add `WorkflowRun` (table `workflow_runs`) per §2.3 with `hub_id` (`NOT NULL`, indexed), `workflow_id` (FK `ON DELETE CASCADE`, indexed), `version_id` (FK `workflow_versions.id`), `trigger` (`manual | api | eval | schedule`), `input_json`, `output_json`, `status` (`queued | running | succeeded | failed | cancelled`), `error_message`, `node_count`, `duration_ms`, `started_by`, `started_at`, `finished_at`. Add a composite index `ix_workflow_runs_wf_started` on `(workflow_id, started_at DESC)` for the run-history table.
- [ ] Extend `EvalFlowTrace` in the same file:
  - `hub_id = Column(String(36), ForeignKey("hubs.id", ondelete="CASCADE"), nullable=False, index=True)`
  - Repoint the existing `run_id` semantics: keep `eval_run_id` for the eval-run linkage and add `run_id = Column(String(36), ForeignKey("workflow_runs.id", ondelete="CASCADE"), nullable=True, index=True)` for the workflow-run linkage, so a trace produced by a workflow run can later be attached to an eval run without being rewritten
  - Widen `workflow_id` from `String(100)` to `String(36)` with `ForeignKey("workflows.id", ondelete="CASCADE")`
  - Add `sequence = Column(Integer, nullable=True)` so the node timeline has a deterministic order independent of timestamp collisions
- [ ] Declare the enum-like value sets as module constants (`WORKFLOW_STATUSES`, `WORKFLOW_RUN_STATUSES`, `WORKFLOW_RUN_TRIGGERS`) and validate them in the Pydantic layer rather than with DB check constraints, matching the project's existing `String`-column convention.
- [ ] Add Pydantic schemas in `common/schemas/workflows.py`: `WorkflowCreate`, `WorkflowUpdate`, `WorkflowSummary`, `WorkflowDetail`, `WorkflowVersionSummary`, `WorkflowVersionDetail`, `WorkflowGraph` (`{nodes: list[dict], edges: list[dict], viewport: dict | None}`), `WorkflowRunSummary`, `WorkflowRunDetail`, `ValidationResult`. `WorkflowDetail` exposes `draft_version_number`, `published_version_number` and `version_etag`.
- [ ] Add Alembic revision `migrations/versions/<rev>_workflow_hub_models.py`:
  - `op.create_table("workflow_versions", ...)`, `op.create_table("workflow_runs", ...)`
  - `op.add_column("workflows", ...)` for `hub_id` (nullable initially), `slug`, `description`, `tags_json`, `status`, `published_version_id`, `draft_version_id`, `created_by`
  - `op.add_column("eval_flow_traces", ...)` for `hub_id` (nullable initially), `run_id`, `sequence`
- [ ] Backfill in the same revision, after the seed hubs from S6-01e exist:
  - Set `workflows.hub_id` to the `workflow/default` hub id
  - Derive `slug` from `slugify(name)`, de-duplicating with a numeric suffix to satisfy `uq_workflows_hub_slug`
  - For each existing workflow, insert one `workflow_versions` row with `version_number=1`, `graph_json` copied from `workflows.graph_json`, `change_note='Migrated from V5'`, `is_valid=true`; set both `draft_version_id` and `published_version_id` to it and `status='published'`
  - Set `eval_flow_traces.hub_id` from the owning workflow's hub, defaulting to `eval/default` for orphans
  - `ALTER COLUMN hub_id SET NOT NULL` on `workflows`, `workflow_runs` and `eval_flow_traces`
  - `op.drop_column("workflows", "graph_json")` and `op.drop_column("workflows", "is_active")` **last**, only after the version rows are verified present
- [ ] Implement `downgrade()`: re-add `graph_json` / `is_active`, copy the published version's graph back onto `workflows`, drop `workflow_runs` and `workflow_versions`, and drop the added `eval_flow_traces` columns.
- [ ] Make the revision idempotent — guard each backfill with `WHERE hub_id IS NULL` / `NOT EXISTS (SELECT 1 FROM workflow_versions WHERE workflow_id = ...)` so re-running against a migrated database is a no-op.
- [ ] Add `tests/fixtures` factories `make_workflow(hub_id, ...)`, `make_version(workflow_id, n, graph)` and `make_run(...)` used by S6-06b–g test suites.
