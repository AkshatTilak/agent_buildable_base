# S6-11b: Frontend Legacy Removal Sweep

> **Parent:** B6-11 (Legacy Decommission, Data Migration & Verification)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend/src`

---

## Scope

Delete every V5 frontend surface that the hub workspaces replace: the flat top-level pages, the legacy
routes in `App.tsx`, the singleton fields in `workflowSlice.ts`, and every `api.ts` helper that calls a
route without a `hubId`. Each item names the file it lives in today and the grep pattern that proves
removal.

Boundary: TypeScript interface cleanup is S6-11c; this subtask removes components, routes, store fields
and API helpers, and repoints any remaining import.
