# S6-05b: Agent ↔ Collection Binding via Hub Links

> **Parent:** B6-05 (Agent Hub — Scoped Agent Lifecycle)  
> **Status:** `[x]`  
> **Complexity:** 🔴 High  
> **Owner:** `projects/guardroute`, `common/services`  

---

## Scope

An agent in an `agent` hub may retrieve from collections that live in `ingestion` hubs. V6 forbids bare
collection ids: every binding is stored as a **qualified reference** `{hub_id, collection_id}` on
`agent_definitions.collection_bindings_json`. This subtask implements the storage shape, the
`hub_resolver` validation performed both when the binding is saved and again immediately before each
retrieval at invocation time, and the two distinct error codes the platform raises when the grant is
missing (`HUB_LINK_REQUIRED`) versus when it was revoked after the binding was authored
(`HUB_LINK_REVOKED`).

It also routes the actual retrieval through the **target** ingestion hub's datastore bindings, so an
agent reading from `ingestion/support-kb` queries that hub's Qdrant binding and physical collection name
(`{hub_slug}__{collection_name}`), never the platform default.

## Actionables

- [ ] Define the binding schema in [`common/schemas/agent_types.py`](file:///c:/Akshat/ContAIned/common/schemas/agent_types.py):
  ```python
  class CollectionBinding(BaseModel):
      hub_id: str          # ingestion hub that owns the collection
      collection_id: str
      alias: str | None = None      # optional name used in the agent's tool description
      top_k: int = 5
  ```
  `AgentCreate` / `AgentUpdate` / `AgentResponse` gain `collection_bindings: list[CollectionBinding] = []`. Reject duplicate `(hub_id, collection_id)` pairs with `422 DUPLICATE_COLLECTION_BINDING`.
- [ ] Add `AgentResponse.collection_bindings[].status` (`ok` | `link_revoked` | `missing`) computed on read so the UI can render a broken-binding badge without a second round trip.
- [ ] Create `projects/guardroute/src/agents/collection_binding.py` with:
  ```python
  async def validate_bindings(session, *, source_hub_id: str, bindings: list[CollectionBinding]) -> None
  async def resolve_bindings(session, *, source_hub_id: str, bindings: list[CollectionBinding]) -> list[ResolvedBinding]
  ```
  - `validate_bindings` is called on create/update; it loops the bindings and calls `common/services/hub_resolver.py::resolve_linked(session, source_hub_id=..., target_resource_type="collection", target_resource_id=...)`
  - `ResolvedBinding` carries the collection row, its owning hub, the hub's resolved `DatastoreBinding` for `store_type="qdrant"`, and the `physical_name`
- [ ] Enforce the **cross-hub security check** explicitly at both points:
  - The referenced collection must actually belong to `binding.hub_id` — a collection id from a third hub passed with a linked `hub_id` must fail with `422 CROSS_HUB_REFERENCE_MISMATCH`
  - A `hub_link` must exist with `source_hub_id = <agent hub>`, `target_hub_id = <ingestion hub>` and `access_level in ("read", "use")`; the direction `agent → ingestion` is the only one accepted per [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §3.3
  - The target hub must not be archived
- [ ] Map resolver failures to HTTP responses in a shared handler so every surface reports them identically:

  | Condition | Status | `error.code` | Message |
  |---|---|---|---|
  | No link at save time | `403` | `HUB_LINK_REQUIRED` | `Agent hub '{a}' is not linked to ingestion hub '{b}'.` |
  | Link existed, absent at invoke time | `403` | `HUB_LINK_REVOKED` | `Hub link to '{b}' was revoked; retrieval aborted.` |
  | Collection not in the stated hub | `422` | `CROSS_HUB_REFERENCE_MISMATCH` | `Collection '{id}' does not belong to hub '{hub_id}'.` |
  | Collection deleted | `404` | `BINDING_TARGET_MISSING` | `Bound collection '{id}' no longer exists.` |

  Response body shape: `{"error": {"code": "...", "message": "...", "hub_id": "...", "target_hub_id": "...", "collection_id": "..."}}`.
- [ ] Re-validate at **execution** time, not just at save time: the agent invocation path calls `resolve_bindings(...)` before building the retrieval tool for every request. Do not cache the link decision beyond the lifetime of a single invocation; revoking a link must break the very next call.
- [ ] Route retrieval through the target ingestion hub's bindings: `resolve_bindings` returns the Qdrant client produced by the S6-04b datastore binding resolver for the *collection's* hub, and the query uses `collection.physical_name` (`{hub_slug}__{name}`) — never a name-only lookup against the platform default client.
- [ ] Record the resolved bindings on the invocation log: write `AgentInvocationLog.metadata_json["collection_bindings"] = [{"hub_id": ..., "collection_id": ..., "chunks_returned": n}]` so trace consumers can see which tenant's data was read.
- [ ] Add a maintenance helper `async def audit_agent_bindings(session, *, hub_id: str) -> list[BindingIssue]` used by the Agent Hub overview to list agents whose bindings are currently broken, without executing them.
- [ ] Add unit tests in `tests/test_agent_hub.py` (created in S6-05e) covering: save with a valid link succeeds; save without a link returns `403 HUB_LINK_REQUIRED`; deleting the link then invoking returns `403 HUB_LINK_REVOKED`; a collection id belonging to a non-linked hub returns `422 CROSS_HUB_REFERENCE_MISMATCH`.
