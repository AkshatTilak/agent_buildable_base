# S6-06e: Workflow Hub API Routes

> **Parent:** B6-06 (Workflow Hub — Multi-Workflow Management & Versioning)  
> **Status:** `[ ]`  
> **Complexity:** 🔴 High  
> **Owner:** `gateway/api`  

---

## Scope

Create `gateway/api/workflows.py` implementing the complete route table from
[`workflow_v6.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/workflow_v6.md) §3.
Every route is nested under `/hubs/{hub_id}/workflows`, guarded by
`require_hub(hub_type="workflow", min_role=...)`, and delegates to the services from S6-06b
(versioning), S6-06d (runs) and S6-06f (import/export) — the route module contains no business logic
beyond request/response mapping, header handling and audit writes.

Special attention goes to `PUT .../draft`, which is the only route in the platform with `If-Match`
semantics, and to `POST .../run`, which returns an SSE stream.

- [ ] Implement `If-Match` handling on `PUT /{wf_id}/draft` precisely:
  - Read the header via `if_match: str | None = Header(default=None, alias="If-Match")`
  - Missing header on a workflow that has a published version → `428 {"error": {"code": "ETAG_REQUIRED"}}`
  - Header value `*` is accepted as an explicit force-overwrite (used by the import path only)
  - Mismatch → catch `DraftConflict` from S6-06b and return `409` with the conflict body containing `server_etag`, `server_version_number`, `server_graph`, `updated_by`, `updated_at`
  - Success → set the response `ETag` header to the recomputed etag and include `version_etag` in the body
  - Also return the current etag as an `ETag` header on `GET /{wf_id}/draft` so the client always has a token to send back
- [ ] Implement `POST /{wf_id}/run`:
  - Body `{"input": {...}, "use_draft": false, "stream": true, "timeout_s": 300}`
  - `stream=true` → call `start_run(...)` then return `StreamingResponse(sse_iter(stream_run(run_id)), media_type="text/event-stream")` with headers `Cache-Control: no-cache`, `X-Accel-Buffering: no`, and `X-Run-Id: <run_id>`
  - `stream=false` → `202 {"run_id": ..., "status": "queued"}` with the run continuing in the background
  - Validation or link errors raised *before* the stream opens must surface as ordinary `422`/`403` JSON responses, never as an SSE error frame
- [ ] Map service exceptions to responses in one place using a router-level exception handler:

  | Exception | Status | `error.code` |
  |---|---|---|
  | `WorkflowNotFound` | `404` | `WORKFLOW_NOT_FOUND` |
  | `DraftConflict` | `409` | `VERSION_CONFLICT` |
  | `WorkflowValidationError` | `422` | `GRAPH_INVALID` (with `errors[]` from S6-06c) |
  | `HubLinkError` | `403` | `HUB_LINK_REQUIRED` / `HUB_LINK_REVOKED` |
  | `HubArchivedError` | `409` | `HUB_ARCHIVED` |
  | `WorkflowNotPublished` | `409` | `WORKFLOW_NOT_PUBLISHED` |
  | duplicate `(hub_id, slug)` | `409` | `WORKFLOW_SLUG_TAKEN` |

- [ ] Enforce hub scoping on every handler by passing `ctx.hub.id` into the service call — never accept a `hub_id` from the body, and never look a workflow, version or run up by primary key alone. A `wf_id` belonging to another hub returns `404 WORKFLOW_NOT_FOUND`, matching [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §5.2.
- [ ] Add the **cross-hub security check** on the two routes that accept a foreign hub id in the body — `POST /{wf_id}/duplicate` (`target_hub_id`) and `POST /import` (`target_hub_id` for remapped references): the caller must additionally hold at least `contributor` on that hub, and the workflow hub must hold a valid `hub_link` for every remapped reference; otherwise `403 HUB_LINK_REQUIRED`.
- [ ] Write exactly one `audit_log` row per mutating route (`create`, `update`, `delete`, `publish`, `restore`, `duplicate`, `import`) with `resource_type="workflow"` and `before_json`/`after_json` populated. Draft autosaves and run executions are **not** audited — they are already captured by `workflow_versions` and `workflow_runs`.
- [ ] Implement `GET /{wf_id}/runs/{run_id}/traces` returning `eval_flow_traces` for that `run_id` ordered by `sequence, timestamp`, filtered by `hub_id`, with `?include_state=false` by default (returns node metadata + latency only) and `?include_state=true` returning the full redacted `input_state`/`output_state`.
- [ ] Set `Content-Disposition: attachment; filename="{slug}-v{n}.workflow.json"` on `GET /{wf_id}/export` and cap `POST /import` request bodies at 5 MB, returning `413 IMPORT_TOO_LARGE` beyond it.
- [ ] Add `tests/test_workflow_routes.py` covering: every route's minimum-role gate; `PUT /draft` without `If-Match` → `428`; with a stale etag → `409` including `server_graph`; a `wf_id` from another hub → `404`; `POST /run` with `stream=true` yields `run_start` … `run_end`; `POST /run` on an unpublished workflow → `409`.
