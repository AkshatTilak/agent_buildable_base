# S6-05e: Agent Hub Migration, Legacy Removal & Tests

> **Parent:** B6-05 (Agent Hub — Scoped Agent Lifecycle)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `migrations`, `gateway/api`, `tests`  

---

## Scope

Close out the Agent Hub cutover. Backfill every existing agent and invocation log row into the
`agent/default` seed hub, tighten both `hub_id` columns to `NOT NULL`, seed the
`agent → ingestion` hub link so V5 retrieval keeps working, and then **delete** the flat `/agents`
routes so no globally-addressed agent surface remains. Finish with `tests/test_agent_hub.py`, the
acceptance suite for B6-05.

This is a hard cutover per [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md)
§6 — no back-compat aliases, no redirect shims.

## Actionables

- [ ] Add Alembic revision `migrations/versions/<rev>_agent_hub_backfill.py` (depends on the S6-01e seed revision) that:
  - Resolves the seed hub id: `SELECT id FROM hubs WHERE hub_type='agent' AND slug='default'`, aborting with a clear `RuntimeError` if absent
  - `UPDATE agent_definitions SET hub_id = :hub WHERE hub_id IS NULL`
  - `UPDATE agent_invocation_log l SET hub_id = (SELECT a.hub_id FROM agent_definitions a WHERE a.id = l.agent_id)` and falls back to the seed hub for orphaned rows
  - Backfills `endpoint_slug` for any agent where it is `NULL`, using a slugified name plus a `-2`, `-3`… suffix to satisfy `uq_agent_definitions_hub_slug`
  - Rewrites any legacy collection reference held on the agent into the qualified form `{"hub_id": <ingestion/default id>, "collection_id": <id>}` inside `collection_bindings_json`
  - `ALTER TABLE ... ALTER COLUMN hub_id SET NOT NULL` on both tables
  - Is idempotent: every `UPDATE` is guarded by `WHERE hub_id IS NULL`, and the seed link insert uses an existence check
- [ ] Ensure the `agent/default → ingestion/default` row in `hub_links` (`access_level='use'`) exists; insert it here if the S6-01e seed did not, so migrated agents keep retrieving.
- [ ] Implement `downgrade()`: drop `uq_agent_definitions_hub_slug`, restore the global unique index on `agent_definitions.endpoint_slug`, set both `hub_id` columns nullable and null them out.
- [ ] Delete the flat routes:
  - Remove the `APIRouter(prefix="/agents", ...)` declaration and every `@router.get("")`, `@router.get("/{agent_id}")`, `@router.post("")`, `@router.put("/{agent_id}")`, `@router.patch("/{agent_id}/toggle")`, `@router.delete("/{agent_id}")` binding left on it in [`gateway/api/agent_crud.py`](file:///c:/Akshat/ContAIned/gateway/api/agent_crud.py)
  - Remove `@router.post("/agents/{agent_id}/invoke")` and the other unnested paths from [`gateway/api/agent_invoke.py`](file:///c:/Akshat/ContAIned/gateway/api/agent_invoke.py)
  - Remove any `include_router` line in [`gateway/main.py`](file:///c:/Akshat/ContAIned/gateway/main.py) that mounts an agent router at a non-hub prefix
- [ ] Grep the repository for surviving callers of the removed paths (`"/agents/"` string literals in `frontend/src/services`, `projects/*/api.py`, `scripts/deploy.py`, `tests/`) and update or delete each; the build must contain zero references to a flat agent URL.
- [ ] Delete or rewrite the V5 agent tests that assert flat behaviour: [`tests/test_agent_api.py`](file:///c:/Akshat/ContAIned/tests/test_agent_api.py), [`tests/test_agent_crud_v5.py`](file:///c:/Akshat/ContAIned/tests/test_agent_crud_v5.py), [`tests/test_agent_invoke.py`](file:///c:/Akshat/ContAIned/tests/test_agent_invoke.py) — port the still-relevant assertions into the new suite rather than leaving duplicated coverage.
- [ ] Create `tests/test_agent_hub.py` with fixtures building two agent hubs (`agent/alpha`, `agent/beta`), one ingestion hub (`ingestion/kb`), and users at each hub role. Cover:
  - Hub scoping: an agent created in `alpha` returns `404` when fetched via `beta`'s path
  - Slug collision: the same `endpoint_slug` may be created in both hubs; a duplicate within one hub returns `409`
  - Role gates: `viewer` gets `403` on create; `contributor` gets `403` on delete; `maintainer` succeeds
  - Link enforcement at save: binding `ingestion/kb` without a link returns `403 HUB_LINK_REQUIRED`
  - Link enforcement at invoke: create the link, bind, delete the link, invoke → `403 HUB_LINK_REVOKED`
  - Invocation logs: a log row written in `alpha` is not visible from `beta`'s `/logs` route
  - External API: `POST /v1/chat/completions` with `model="alpha/triage"` resolves; `model="triage"` returns `404 model_not_found`
  - `GET /v1/models` with a key scoped to `alpha` omits every `beta` agent
- [ ] Add a regression assertion that no module under `gateway/` or `projects/` selects `AgentDefinition` or `AgentInvocationLog` by primary key alone, extending the shared guard from `tests/test_hub_isolation.py`.
- [ ] Verify the migration end-to-end against a populated V5 dump: run `alembic upgrade head`, assert every agent has a non-null `hub_id`, run `alembic downgrade -1`, then `upgrade head` again and assert row counts are unchanged.
