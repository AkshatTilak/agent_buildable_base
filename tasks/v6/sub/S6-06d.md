## Scope

Execute a specific **version** of a workflow — the published version by default, or the draft when the
caller asks for a dry run — and make the execution durable. Every run inserts a `workflow_runs` row,
every node emits an `eval_flow_traces` row linked by `run_id`, and progress streams to the client over
SSE using the V5 conventions (`node_start`, `node_end`, `run_end`). Runs are cancellable and are bounded
by a wall-clock timeout.

The V5 singleton entry point `execute_orchestrator_stream(prompt, session_id)` in
[`projects/guardroute/src/orchestrator.py`](file:///c:/Akshat/ContAIned/projects/guardroute/src/orchestrator.py)
is replaced by a version-addressed runner. Route wiring is S6-06e; this subtask delivers the runner and
its persistence.

## Actionables

- [x] Create `projects/guardroute/src/workflows/run_service.py` exposing:
  ```python
  async def start_run(session, *, hub_id: str, workflow_id: str, input_json: dict,
                      trigger: Literal["manual","api","eval","schedule"],
                      started_by: str | None, use_draft: bool = False,
                      timeout_s: int = 300) -> WorkflowRun
  async def stream_run(run_id: str) -> AsyncGenerator[dict, None]
  async def cancel_run(session, *, hub_id: str, run_id: str, actor_id: str) -> WorkflowRun
  async def get_run(session, *, hub_id: str, run_id: str) -> WorkflowRunDetail
  async def list_runs(session, *, hub_id: str, workflow_id: str, status: str | None,
                      limit: int = 50, offset: int = 0) -> list[WorkflowRunSummary]
  ```
- [x] Resolve the version to execute inside `start_run`:
  - `use_draft=False` → `workflow.published_version_id`; if `None`, fail with `409 WORKFLOW_NOT_PUBLISHED`
  - `use_draft=True` → `workflow.draft_version_id`; the run is recorded with `trigger="manual"` and `input_json["_dry_run"] = True`
  - Persist `workflow_runs.version_id` so a run is always reproducible against the exact frozen graph, even after later edits
- [x] Insert the `workflow_runs` row with `status="queued"` **before** execution begins and flip it to `running` when the first node starts, so a crashed worker leaves an inspectable row rather than nothing.
- [x] Re-validate every qualified node reference immediately before the owning node executes, using `validate_workflow_graph(..., strict=True)` scoped to that node (S6-06c). On failure abort with `status="failed"`, `error_message="HUB_LINK_REVOKED: node <id> references <hub>/<resource>"`, and emit a terminal `run_end` SSE event. Do **not** pre-resolve once at run start and reuse the decision — the check must reflect link state at node execution time per [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §5.4.
- [x] Emit one `eval_flow_traces` row per node with `hub_id` (the workflow hub), `run_id` (the `workflow_runs.id`), `workflow_id`, `node_id`, `node_type`, `input_state`, `output_state`, `latency_ms`, `sequence` (monotonic from 0) and `timestamp`. Reuse the existing non-blocking queue in [`projects/evalops/src/runner/trace_collector.py`](file:///c:/Akshat/ContAIned/projects/evalops/src/runner/trace_collector.py) via `TraceCollector.emit_event(...)` rather than introducing a second tracing mechanism — extend its event payload with `hub_id` and `sequence`.
- [x] Redact secrets before persisting trace state: strip any key matching `(?i)(authorization|api[_-]?key|token|password|secret)` from `input_state` / `output_state`, replacing the value with `"***"`.
- [x] Define the SSE event contract exactly, reusing the V5 `data: {json}\n\n` framing:
  ```text
  event: run_start   data: {"run_id","workflow_id","version_id","version_number","node_count"}
  event: node_start  data: {"run_id","node_id","node_type","sequence","started_at"}
  event: node_end    data: {"run_id","node_id","status":"succeeded|failed|skipped","latency_ms","output_preview","sequence"}
  event: run_end     data: {"run_id","status","duration_ms","output","error":{"code","message","node_id"}|null}
  ```
  `output_preview` is truncated to 2000 characters; the full state is available from the trace endpoint. Always emit exactly one `run_end`, including on error, cancellation and timeout, then close the stream.
- [x] Publish run events to Redis (`workflow-run-events:{run_id}`) and have `stream_run` subscribe, so an SSE consumer can attach after `start_run` returns and multiple viewers can watch the same run. Replay any events already buffered for the run before switching to live subscription.
- [x] Implement cancellation: `cancel_run` sets `status="cancelled"` and publishes a cancel signal; the runner checks a cancellation flag between nodes and, on observing it, stops scheduling further nodes, writes `finished_at`, and emits `run_end` with `status="cancelled"`. A run already in a terminal state returns `409 RUN_NOT_CANCELLABLE`.
- [x] Implement timeout and failure handling:
  - Wrap the whole execution in `asyncio.wait_for(..., timeout=timeout_s)`; on `TimeoutError` set `status="failed"`, `error_message="RUN_TIMEOUT after {n}s"`
  - A node exception marks the run `failed`, records `error_message` as `"{code}: {message}"` and stores the failing `node_id` in `output_json["failed_node_id"]`; traces already emitted are retained
  - Always set `finished_at`, `duration_ms` and `node_count` in a `finally` block so no row is left in `running`
- [x] Add a startup reconciliation hook in [`gateway/main.py`](file:///c:/Akshat/ContAIned/gateway/main.py) that marks any `workflow_runs` row left in `queued`/`running` from a previous process as `failed` with `error_message="ORPHANED_RUN"`.
- [x] Enforce hub scoping on every read: `get_run`, `list_runs` and `cancel_run` filter on both `id` and `hub_id`; a run id from another hub returns `404 RUN_NOT_FOUND`.
- [x] Add `tests/test_workflow_runs.py` covering: a published run persists a row plus one trace per node; a dry run against the draft is permitted while the published version is stale; revoking a link mid-graph fails the run with `HUB_LINK_REVOKED`; cancellation produces a single `run_end` with `status="cancelled"`; a timeout marks the run `failed`; a run id from another hub returns `404`.
