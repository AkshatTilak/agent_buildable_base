## Scope

Make the removals of S6-11a/b/c permanent by encoding them as an executable guard. `scripts/verify_v6_cutover.py`
walks the repository, applies a declared pattern list, and exits non-zero if any removed symbol, route,
column, role literal or component name reappears outside the documentation trees (`agent_buildable_base/tasks/`
and `agent_buildable_base/references/`, which legitimately describe what was removed).

Boundary: the script is a **static** guard only — behavioural verification lives in S6-11f and the
migration harness in S6-11d.
