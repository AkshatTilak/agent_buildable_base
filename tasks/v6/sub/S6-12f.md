## Scope

Make the hub shell hold its layout from 1280px to 2560px, collapse gracefully below 1024px, keep long
lists fast through virtualisation, and cut initial bundle weight with route-level code splitting —
including lazy-loading ReactFlow, which only the workflow editor needs. Finishes with an explicit
no-regression check against the V4 typography and truncation work.

Boundary: layout, virtualisation, bundling and truncation behaviour. Component APIs come from S6-12b and
must not be forked here.

## Actionables

- [x] Audit and fix layout integrity at 1280, 1440, 1920, 2560px for the hub directory, each hub workspace, the workflow editor, the eval results dashboard and the admin console:
  - [x] Content max-width and centred gutters at ≥ 2000px so tables do not stretch to unreadable line lengths.
  - [x] No horizontal page scroll at any breakpoint; only `DataTable` may scroll horizontally, and it keeps its sticky header and first column aligned while doing so.
- [x] Implement sidebar collapse below 1024px in [frontend/src/components/Sidebar.tsx](frontend/src/components/Sidebar.tsx): icon-rail mode with tooltips, an off-canvas drawer for the expanded state, focus trapped while open (S6-12d), and the collapsed/expanded preference persisted in `frontend/src/store/settingsSlice.ts`.
- [x] Make the workflow editor viable below 1440px: the property drawer becomes an overlay rather than a fixed column, and the version rail collapses to a toggle button.
- [x] Add virtualisation via a single shared strategy (`frontend/src/components/shared/useVirtualRows.ts`) wired into the `DataTable` `virtualise` prop, and adopt it on: documents, chunks, agent invocation logs, workflow runs, node traces, eval cases/results, and the audit log.
  - [x] Assert smooth scrolling with a 10,000-row fixture and no measurable frame drops while scrolling; row height comes from the density tokens so virtual and real heights agree.
- [x] Apply route-level code splitting in [frontend/src/App.tsx](frontend/src/App.tsx) with `React.lazy` + `Suspense` per route group (hub directory, each hub workspace, admin console, platform surfaces, auth screens), using the S6-12c skeletons as the `Suspense` fallback — never a bare spinner.
- [x] Lazy-load ReactFlow and the node components in `frontend/src/components/nodes/` so `reactflow` appears only in the workflow-editor chunk.
  - [x] Proof: the build output shows no `reactflow` code in the entry chunk, and navigating to `/hubs` never requests the editor chunk.
- [x] Lazy-load charting for the eval dashboard and system metrics so chart libraries do not load on routes that render no chart.
- [x] Record a bundle budget in the repo (entry chunk gzipped ceiling) and add a build-time check that fails when the entry chunk exceeds it; capture the before/after sizes in the task log.
