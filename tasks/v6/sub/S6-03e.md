# S6-03e: Mailer Abstraction, SMTP & Templates

> **Parent:** B6-03 (Admin User Management, Invitations & Approval Gate)  
> **Status:** `[ ]`  
> **Complexity:** 🟢 Low  
> **Owner:** `gateway/services/mailer.py`  

---

## Scope

Provide the platform's only outbound email path: a `Mailer` protocol with an `aiosmtplib`-backed
implementation, a no-op fallback for unconfigured deployments, and the four HTML + plain-text templates
used by invites, approvals, rejections and password resets. The module must degrade gracefully — a
missing or broken SMTP configuration never fails an API request, it only flips `delivered` to `false`.

This subtask also registers every new V6 environment variable on `common/config/settings.py`, which
today has no SMTP, invite-TTL, public-URL or self-registration settings at all.

## Actionables

- [ ] Add `aiosmtplib (>=3.0.0,<4.0.0)` and `jinja2 (>=3.1.0,<4.0.0)` to the gateway dependency group
      in `pyproject.toml`.
- [ ] Create `gateway/services/mailer.py`:
  ```python
  class Mailer(Protocol):
      async def send(self, to: str, subject: str, html: str, text: str) -> bool: ...

  class SMTPMailer:
      def __init__(self, host: str, port: int, user: str | None, password: str | None,
                   sender: str, use_tls: bool) -> None: ...
      async def send(self, to: str, subject: str, html: str, text: str) -> bool: ...

  class NullMailer:
      async def send(self, to: str, subject: str, html: str, text: str) -> bool:
          logger.warning("SMTP not configured; email to %s dropped (subject=%s)", to, subject)
          return False

  @lru_cache(maxsize=1)
  def get_mailer() -> Mailer:
      """Returns SMTPMailer when SMTP_HOST is set, otherwise NullMailer."""
  ```
- [ ] Implement `SMTPMailer.send` with `email.message.EmailMessage`, setting the plain-text body and
      attaching the HTML alternative via `add_alternative(html, subtype="html")`:
  - Use `aiosmtplib.send(..., start_tls=self.use_tls)` for port `587` and `use_tls=True` (implicit TLS)
    for port `465`; never fall back to an unencrypted connection when `SMTP_USE_TLS` is true.
  - Apply a 10-second timeout and catch `aiosmtplib.SMTPException`, `OSError` and `asyncio.TimeoutError`,
    log at `WARNING` with the recipient and subject, and return `False` — **never** re-raise into a request.
  - Never log the SMTP password, the message body, or any token contained in it.
- [ ] Create `gateway/templates/email/` with eight files: `invite.html`/`invite.txt`,
      `approved.html`/`approved.txt`, `rejected.html`/`rejected.txt`,
      `password_reset.html`/`password_reset.txt`.
  - Render with a sandboxed `jinja2.Environment(loader=FileSystemLoader(...), autoescape=select_autoescape(["html"]))`
    so template variables in the HTML variants are HTML-escaped.
  - `invite` variables: `inviter_name`, `platform_role`, `hub_names`, `invite_url`, `expires_at`.
  - `approved` variables: `display_name`, `app_url`. `rejected`: `display_name`, `reason` (optional).
  - `password_reset` variables: `display_name`, `reset_url`, `ttl_minutes`.
- [ ] Add `async def send_template(to: str, template: str, subject: str, **context) -> bool` as the
      single entry point used by S6-03d and S6-03f, resolving `{template}.html` + `{template}.txt`,
      injecting `app_url = settings.APP_PUBLIC_URL` into every context.
- [ ] Add a `MailSettings(BaseSettings)` class to `common/config/settings.py` and include it in the
      `Settings(...)` multi-inheritance list alongside `AuthSettings`:
  ```python
  SMTP_HOST: Optional[str] = Field(default=None, alias="SMTP_HOST")
  SMTP_PORT: int = Field(default=587, alias="SMTP_PORT")
  SMTP_USER: Optional[str] = Field(default=None, alias="SMTP_USER")
  SMTP_PASSWORD: Optional[str] = Field(default=None, alias="SMTP_PASSWORD")
  SMTP_FROM: str = Field(default="ContAIned <no-reply@contained.local>", alias="SMTP_FROM")
  SMTP_USE_TLS: bool = Field(default=True, alias="SMTP_USE_TLS")
  INVITE_TTL_HOURS: int = Field(default=72, alias="INVITE_TTL_HOURS")
  PASSWORD_RESET_TTL_MINUTES: int = Field(default=60, alias="PASSWORD_RESET_TTL_MINUTES")
  APP_PUBLIC_URL: str = Field(default="http://localhost:5173", alias="APP_PUBLIC_URL")
  ALLOW_SELF_REGISTRATION: bool = Field(default=True, alias="ALLOW_SELF_REGISTRATION")
  ALLOW_MEMBER_HUB_CREATION: bool = Field(default=True, alias="ALLOW_MEMBER_HUB_CREATION")
  AUTO_APPROVE_EMAIL_DOMAINS: str = Field(default="", alias="AUTO_APPROVE_EMAIL_DOMAINS")
  DATASTORE_ENCRYPTION_KEY: Optional[str] = Field(default=None, alias="DATASTORE_ENCRYPTION_KEY")
  ```
  - Add a `@model_validator(mode="after")` rule that raises when `APP_ENV == "production"` and
    `DATASTORE_ENCRYPTION_KEY` is unset, and that warns (not raises) when `SMTP_HOST` is unset.
  - Add a helper property `auto_approve_domains: list[str]` parsing the CSV into a lowercased,
    stripped list so callers never re-parse it.
- [ ] Mirror every new variable in `.env.example` with the documented defaults and an inline comment
      for `AUTO_APPROVE_EMAIL_DOMAINS` (`# optional CSV, e.g. "acme.com" -> skip approval gate`).
- [ ] Document the fallback contract in the module docstring: callers must treat `send()` returning
      `False` as a **successful API call with undelivered mail**, surfacing
      `{"delivered": false, "invite_url": ...}` to the creating admin only, once.
- [ ] Ensure `gateway/templates/` is shipped in the container by adding it to the package data /
      `COPY` layer in `infrastructure/Dockerfile.gateway`.
