# S6-12d: Keyboard & Accessibility Pass

> **Parent:** B6-12 (UX, Interaction & Accessibility Uplift)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `frontend/src`

---

## Scope

Make the whole V6 surface operable without a mouse and legible to assistive technology: visible focus
rings, focus trapping and restoration in overlays, `Esc` handling, accessible names for icon-only
controls, correct table semantics, live regions for async status, status meaning carried by more than
colour, and a WCAG AA contrast audit of the dark theme. Ends with a discoverable shortcut sheet on `?`.

Boundary: this hardens components built in S6-12b and surfaces built in B6-08 … B6-10; it does not add
new features.

## Actionables

- [x] Apply a global visible focus ring using the `--focus-ring` / `--focus-ring-offset` tokens from S6-12a via `:focus-visible` in [frontend/src/index.css](frontend/src/index.css); remove every `outline: none` that is not immediately replaced by an equivalent indicator.
  - [x] Proof: `grep -rn "outline: *none\|outline:0" frontend/src` → each remaining hit is paired with a `:focus-visible` rule on the same selector.
- [x] Implement `frontend/src/hooks/useFocusTrap.ts` and adopt it in `Drawer.tsx`, `ConfirmModal.tsx`, `CreateWorkflowDialog.tsx`, `ConflictDialog.tsx`, `RunConfigModal.tsx` and the command palette: focus moves to the first interactive element on open, `Tab`/`Shift+Tab` cycle within, and focus returns to the invoking element on close.
- [x] Standardise `Esc` handling: closes the topmost overlay only (drawer, modal, popover, tooltip, command palette), never navigates; a dirty form asks for confirmation before closing instead of discarding silently.
- [x] Give every icon-only button an accessible name — sidebar toggles, table row overflow menus, `CopyButton`, canvas toolbar buttons in the workflow editor, node handles, the density switch — using `aria-label` plus a `Tooltip` with matching text.
  - [x] Proof: an audit script or lint rule flags any `<button>` whose children contain only an icon component and which lacks `aria-label`; 0 violations.
- [x] Fix table semantics in `DataTable.tsx`: real `<table>/<thead>/<tbody>/<th scope="col">`, `aria-sort` on the active sort column, `aria-rowcount`/`aria-rowindex` when virtualised, row checkboxes labelled with the row's primary identifier, and the bulk bar announced when it appears.
- [x] Add live regions: a polite `aria-live` region announcing save-state changes in the workflow editor (`Saved`, `Unsaved changes`, `Conflict`), run status transitions in `WorkflowRuns`/`EvalResults`, toast messages, and the copy confirmation; use `aria-live="assertive"` only for errors that block the user.
- [x] Ensure colour is never the sole carrier of meaning: every `Chip` with `variant="status"` renders an icon or text label alongside the colour, workflow-editor node error highlighting adds an icon badge, and eval pass/fail badges include ✓/✕ glyph plus text.
- [x] Audit contrast across the dark theme against WCAG AA (4.5:1 body, 3:1 large text and UI boundaries): all `--text-*` on all `--bg-*` combinations, every `--status-*-fg` on its `-soft` background, hub accents on card backgrounds, and disabled-state text; record the measured ratios and fix or retune failing tokens in [frontend/src/index.css](frontend/src/index.css).
  - [x] Explicitly verify `--text-muted` (`#56596B`) and `--text-disabled` (`#3A3D4A`) against `--bg-surface` and `--bg-card`; lighten them if they fail rather than leaving a known violation.
- [x] Add skip links and landmark roles to the hub shell: "Skip to content", `<nav>` for the sidebar, `<main>` for the workspace, `<header>` for the page header, each labelled.
- [x] Extend [frontend/src/components/layout/CommandPalette.tsx](frontend/src/components/layout/CommandPalette.tsx) to the `Cmd+K` hub switcher contract with a `combobox`/`listbox` role pair, `aria-activedescendant`, and results grouped by hub type.
- [x] Build `frontend/src/components/shared/ShortcutSheet.tsx` opened by `?` (when focus is not in a text field), listing global, table, editor and eval shortcuts grouped by context, closable with `Esc`, and reachable from a help affordance in the shell.
- [x] Verify with tooling and record results: `axe` (or equivalent) run against the hub directory, a hub workspace, the workflow editor, the admin console and each auth screen — zero critical/serious violations; plus a manual keyboard-only walkthrough of create-hub → create-workflow → publish → run.
