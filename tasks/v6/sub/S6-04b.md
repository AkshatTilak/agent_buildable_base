## Scope

Let an ingestion hub own the physical databases that store its data. This subtask delivers
`projects/syntraflow/src/datastores/binding_manager.py`: CRUD and connection testing for `qdrant`,
`neo4j`, `postgres` and `opensearch` bindings, Fernet encryption of credentials at rest, URI masking on
read, the single-default-per-`(hub_id, store_type)` rule, and a periodic health check.

It also centralises client construction. Today `common/clients/qdrant.py::VectorClient` and
`common/clients/neo4j.py::get_neo4j_driver()` read connection details straight from
`common/config/settings.py`, so every caller is hard-wired to the platform instance. After this
subtask, hub-scoped code obtains clients exclusively through `resolve_vector_client(hub_id)` and
`resolve_graph_client(hub_id)`.

## Actionables

- [x] Create `projects/syntraflow/src/datastores/binding_manager.py` with
      `class DatastoreBindingManager` operating on the `DatastoreBinding` model from S6-01b, exposing:
  ```python
  async def create_binding(self, *, hub_id: str, name: str, store_type: str,
                           connection_uri: str, credentials: dict | None,
                           is_default: bool = False, config: dict | None = None) -> DatastoreBinding
  async def list_bindings(self, *, hub_id: str, store_type: str | None = None) -> list[dict]
  async def get_binding(self, *, hub_id: str, binding_id: str) -> dict | None
  async def update_binding(self, *, hub_id: str, binding_id: str, **fields) -> dict
  async def delete_binding(self, *, hub_id: str, binding_id: str) -> None
  async def test_connection(self, *, hub_id: str, binding_id: str | None = None,
                            draft: dict | None = None) -> ConnectionTestResult
  ```
  - Every method takes `hub_id` and filters on it; a binding id alone is never sufficient.
  - `store_type` must be one of `("qdrant", "neo4j", "postgres", "opensearch")` → `422` otherwise.
- [x] Implement credential encryption in `projects/syntraflow/src/datastores/crypto.py`:
  ```python
  from cryptography.fernet import Fernet, InvalidToken

  def _fernet() -> Fernet:            # built from settings.DATASTORE_ENCRYPTION_KEY
  def encrypt_credentials(payload: dict) -> str    # json -> utf-8 -> Fernet token
  def decrypt_credentials(blob: str | None) -> dict
  ```
  - Raise a startup-time `RuntimeError` when `DATASTORE_ENCRYPTION_KEY` is missing and any binding row
    exists; never fall back to plaintext storage.
  - `decrypt_credentials` is called **only** inside client construction — never in a serialiser.
- [x] Implement URI masking used by every read path:
  ```python
  def mask_uri(uri: str) -> str:
      """postgresql://user:secret@host:5432/db -> postgresql://user:***@host:5432/db"""
  ```
  - The API response model (`DatastoreBindingResponse`) exposes `connection_uri` masked and has **no**
    `credentials_encrypted` field at all; add a test asserting the field name never appears in any
    serialised response.
- [x] Enforce the constraints from `hubs.md` §3.4:
  - `UNIQUE (hub_id, name)` → `409` on collision.
  - At most one `is_default = true` per `(hub_id, store_type)`: when a binding is created or updated
    with `is_default=True`, clear the flag on siblings inside the same transaction.
  - Deleting a binding referenced by `syntraflow_collections.datastore_binding_id` returns
    `409 {"detail": "Binding is in use", "collections": [...]}`.
- [x] Implement `test_connection` per store type, with a 5-second timeout, returning
      `ConnectionTestResult{ok: bool, latency_ms: float, detail: str, version: str | None}`:
  - `qdrant` — `QdrantClient(url=..., api_key=...).get_collections()`.
  - `neo4j` — `AsyncGraphDatabase.driver(...).verify_connectivity()`.
  - `postgres` — `create_async_engine(uri).connect()` then `SELECT 1`.
  - `opensearch` — `GET /` and read `version.number`.
  - Support testing an unsaved `draft` payload so the UI can validate before persisting.
  - Never echo the credentials back in `detail`; on failure return the exception class name and a
    sanitised message only.
- [x] Implement `async def run_health_checks(session) -> None` iterating all bindings, calling
      `test_connection`, and writing `health_status` (`healthy` | `degraded` | `unreachable`) and
      `last_health_check`; register it as an `asyncio` background task on the gateway lifespan in
      `gateway/main.py` at a 60-second interval, with failures logged and swallowed.
- [x] Create `projects/syntraflow/src/datastores/resolver.py` with the two resolution entry points:

  ```python
  async def resolve_vector_client(session, hub_id: str) -> VectorClient
  async def resolve_graph_client(session, hub_id: str) -> AsyncDriver
  async def resolve_relational_engine(session, hub_id: str) -> AsyncEngine
  ```
  - Selection order: the hub's `is_default` binding of that `store_type` → the hub's single binding of
    that type → the synthetic platform default.
  - Cache constructed clients in a module-level `dict[tuple[str, str], Any]` keyed

  - When the selected binding's `health_status == "unreachable"`, raise

    the platform default.
- [x] Surface the synthetic **Platform Default** binding: when a hub has no binding of a given

      `{"id": "platform-default:<store_type>", "name": "Platform Default", "is_synthetic": true, "connection_uri": mask_uri(settings.QDRANT_URL | NEO4J_URL | DATABASE_URL), "is_default": true}`.
  - Any write targeting a `platform-default:*` id returns `409 {"detail": "Platform default binding is read-only"}`.
- [x] Add `cryptography (>=42.0.0,<43.0.0)` and `opensearch-py (>=2.4.0,<3.0.0)` to the syntraflow
