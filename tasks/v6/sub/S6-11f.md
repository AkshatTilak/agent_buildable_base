# S6-11f: Full-System Verification Matrix

> **Parent:** B6-11 (Legacy Decommission, Data Migration & Verification)  
> **Status:** `[ ]`  
> **Complexity:** 🔴 High  
> **Owner:** `tests`, `scripts`

---

## Scope

Execute and record an end-to-end verification matrix covering both installation paths (fresh and
migrated), all four hub types, the invite/approval flows with and without SMTP, cross-hub denial, the
external API, the frontend build and the docker profiles. Every cell is a concrete, repeatable check
with a stated pass condition; the completed matrix is the release gate for V6.

Boundary: this is behavioural verification of the assembled system. Static removal checks are S6-11e and
migration internals are S6-11d.
