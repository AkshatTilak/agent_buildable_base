# S6-01f: Hub Schemas & Scoped Repository Layer

> **Parent:** B6-01 (Hub Domain Model & Tenancy Foundation)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `common/schemas`, `common/services`

---

## Scope

Provide the transport and data-access layer that sits on top of the V6 tenancy models: Pydantic v2 schemas
in `common/schemas/hubs.py` for hubs, members, links, datastore bindings and audit entries, and a
`common/services/hub_repository.py` whose function signatures make hub scoping **structurally
unavoidable** — every read helper takes `hub_id` as a required keyword-only argument and injects it into
the `WHERE` clause.

This layer is deliberately transport-agnostic: no FastAPI imports, no `HTTPException`. Authorisation lives
in `S6-02b`; this subtask only guarantees that a correctly-authorised caller cannot accidentally issue an
unscoped query.

## Actionables

- [ ] Create `common/schemas/hubs.py` using Pydantic v2 conventions already used in `common/schemas/api.py`
      (`model_config = ConfigDict(from_attributes=True)`), typing the vocabularies with `Literal` sourced
      from `common/models/hub_enums.py`:
  ```python
  HubType = Literal["ingestion", "agent", "workflow", "eval"]
  HubRole = Literal["owner", "maintainer", "contributor", "viewer"]
  LinkAccess = Literal["read", "use"]
  StoreType = Literal["qdrant", "neo4j", "postgres", "opensearch"]
  ```
- [ ] Define the hub schemas. `hub_type` is present on create and **absent from update** so immutability
      is enforced by the type system rather than by a runtime check:
  ```python
  class HubCreate(BaseModel):
      name: str = Field(min_length=1, max_length=120)
      hub_type: HubType
      slug: str = Field(pattern=r"^[a-z0-9](?:[a-z0-9-]{0,62}[a-z0-9])?$", max_length=64)
      description: str | None = Field(default=None, max_length=2000)
      accent: str | None = Field(default=None, max_length=20)
      icon: str | None = Field(default=None, max_length=40)
      settings_json: dict = Field(default_factory=dict)

  class HubUpdate(BaseModel):      # no hub_type, no owner_id, no is_archived
      name: str | None = None
      slug: str | None = None
      description: str | None = None
      accent: str | None = None
      icon: str | None = None
      settings_json: dict | None = None

  class HubSummary(BaseModel):     # for the hub directory / switcher
      id: str; slug: str; name: str; hub_type: HubType
      accent: str | None; icon: str | None; is_archived: bool
      my_role: HubRole | None = None
      member_count: int = 0
      resource_count: int = 0

  class HubRead(HubSummary):
      description: str | None; settings_json: dict
      owner_id: str; created_at: datetime; updated_at: datetime
  ```
  - Add a `@field_validator("slug")` that lowercases and rejects the reserved words `new`, `admin`,
    `settings` (they collide with frontend routes in `hubs.md` §8).
- [ ] Define the membership and link schemas, including the payload the API returns to the frontend:
  - `HubMemberCreate(user_id: str | None, email: EmailStr | None, hub_role: HubRole)` — exactly one of
    `user_id` / `email` must be supplied (model validator).
  - `HubMemberUpdate(hub_role: HubRole)`.
  - `HubMemberRead(id, user_id, email, display_name, avatar_url, hub_role, invited_by, created_at)`.
  - `HubLinkCreate(target_hub_id: str, access_level: LinkAccess = "read")`.
  - `HubLinkRead(id, source_hub_id, target_hub_id, target_hub_name, target_hub_type, target_hub_slug, access_level, created_by, created_at)` —
    denormalised target fields so the UI never needs an N+1 fetch.
- [ ] Define the datastore-binding schemas with the secret boundary enforced in the schema itself:
  ```python
  class DatastoreBindingCreate(BaseModel):
      name: str = Field(max_length=120)
      store_type: StoreType
      connection_uri: str = Field(max_length=500)
      credentials: SecretStr | None = None       # plaintext IN only; never echoed
      is_default: bool = False
      config_json: dict = Field(default_factory=dict)

  class DatastoreBindingRead(BaseModel):
      id: str | None; hub_id: str | None; name: str; store_type: StoreType
      connection_uri: str                        # ALWAYS mask_connection_uri() output
      has_credentials: bool                      # boolean only — never the value
      is_default: bool; health_status: str; last_health_check: datetime | None
      is_platform_default: bool = False
      config_json: dict
  ```
  - There is **no** `credentials` / `credentials_encrypted` field on any `*Read` schema. Add a comment
    stating this is a security invariant covered by a test.
  - `DatastoreBindingUpdate` mirrors create with all fields optional; `credentials=None` means "leave
    unchanged", and an explicit empty string means "clear".
- [ ] Define `AuditLogRead(id, hub_id, hub_name, actor_user_id, actor_email, action, resource_type, resource_id, summary, before_json, after_json, ip_address, created_at)`
      plus `AuditLogFilter(hub_id, actor_user_id, action, resource_type, resource_id, since, until, limit, offset)`
      for the `/admin/audit` viewer.
- [ ] Create `common/services/hub_repository.py`. Every function is `async`, takes an
      `AsyncSession` first, and uses **keyword-only** `hub_id` so a positional-argument mistake cannot
      silently drop the scope:
  ```python
  async def get_hub(session, hub_id: str) -> Hub | None: ...
  async def get_hub_by_slug(session, *, hub_type: str, slug: str) -> Hub | None: ...
  async def list_hubs_for_user(
      session, *, user_id: str, hub_type: str | None = None,
      include_archived: bool = False, is_platform_admin: bool = False,
  ) -> list[tuple[Hub, str]]: ...          # (hub, effective_role)
  async def create_hub(session, *, data: HubCreate, owner_id: str) -> Hub: ...
  async def update_hub(session, *, hub_id: str, data: HubUpdate) -> Hub: ...
  async def archive_hub(session, *, hub_id: str, archived: bool) -> Hub: ...
  async def delete_hub_if_empty(session, *, hub_id: str) -> None: ...
  ```
  - `create_hub` inserts the `hubs` row **and** the owner's `hub_members` row in one transaction; a hub
    can never exist without an owner membership.
  - `list_hubs_for_user` joins `hub_members`; when `is_platform_admin` it skips the join and reports
    `"owner"` as the effective role for every hub (`hubs.md` §4.2).
  - `delete_hub_if_empty` counts rows across `HUB_SCOPED_MODELS` for the hub and raises
    `HubNotEmptyError` when any is non-zero.
- [ ] Add the membership, link and binding helpers to the same module:
  ```python
  async def get_membership(session, *, hub_id: str, user_id: str) -> HubMember | None: ...
  async def list_members(session, *, hub_id: str) -> list[HubMember]: ...
  async def upsert_member(session, *, hub_id: str, user_id: str, hub_role: str, invited_by: str | None) -> HubMember: ...
  async def remove_member(session, *, hub_id: str, user_id: str) -> None: ...
  async def count_owners(session, *, hub_id: str) -> int: ...
  async def list_links(session, *, source_hub_id: str) -> list[HubLink]: ...
  async def get_link(session, *, source_hub_id: str, target_hub_id: str) -> HubLink | None: ...
  async def list_bindings(session, *, hub_id: str) -> list[DatastoreBinding]: ...
  ```
  - `count_owners` exists so `S6-02d` can enforce last-owner protection without duplicating the query.
- [ ] Add the generic scoped accessor that every downstream feature module must use instead of hand-rolled
      `select(...)` statements — this is the single choke point the guard test in `S6-02e` allowlists:
  ```python
  async def get_scoped(session, model: type[T], *, hub_id: str, resource_id: str) -> T | None:
      """Fetch a hub-scoped row by id AND hub_id. Returns None (not a 403) when the row belongs
      to another hub, so callers naturally emit 404 and cannot leak existence."""
      if not getattr(model, "__hub_scoped__", False):
          raise TypeError(f"{model.__name__} is not hub-scoped; use a plain query")
      stmt = select(model).where(model.id == resource_id, model.hub_id == hub_id)
      return (await session.execute(stmt)).scalar_one_or_none()

  async def list_scoped(session, model: type[T], *, hub_id: str, limit: int = 50, offset: int = 0,
                        order_by=None, extra_filters: Sequence = ()) -> list[T]: ...
  ```
- [ ] Define the repository's exception vocabulary in `common/services/hub_repository.py` (plain
      exceptions, no HTTP semantics): `HubNotFoundError`, `HubArchivedError`, `HubNotEmptyError`,
      `LastOwnerError`, `DuplicateSlugError`, `InvalidLinkDirectionError`. `S6-02b` / `S6-02d` map these to
      status codes.
- [ ] Export the schemas from `common/schemas/__init__.py` and the repository symbols from
      `common/services/__init__.py`, matching the existing export style in those files.
- [ ] Add `tests/test_hub_repository.py`:
  - `get_scoped` returns the row for the owning hub and `None` for a foreign `hub_id`.
  - `get_scoped` raises `TypeError` for a non-hub-scoped model (e.g. `ModelRegistryModel`).
  - `create_hub` produces exactly one `hubs` row and one `hub_members` row with `hub_role="owner"`.
  - `list_hubs_for_user` excludes archived hubs by default and returns `"owner"` for a platform admin who
    holds no membership.
  - `delete_hub_if_empty` raises `HubNotEmptyError` when a single hub-scoped row exists.
  - Serialising a `DatastoreBinding` through `DatastoreBindingRead` never emits a key matching
    `credential|password|secret|token` (assert over `model_dump()` keys **and** values).
