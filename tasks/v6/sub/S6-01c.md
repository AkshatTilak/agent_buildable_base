# S6-01c: Propagate `hub_id` Across Domain Models

> **Parent:** B6-01 (Hub Domain Model & Tenancy Foundation)  
> **Status:** `[x] Completed`  
> **Complexity:** 🔴 High  
> **Owner:** `common/models`, `projects/syntraflow`

---

## Scope

Attach `hub_id` to every domain table listed in
[`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §3.6, with the exact
nullability that table requires, and rebuild the uniqueness constraints per §3.7 so friendly names become
per-hub rather than global. Add `physical_name` to `syntraflow_collections` so the Qdrant collection name
stays globally unique as `{hub_slug}__{name}` while the user-facing name is scoped to the hub. Introduce a
`HubScopedMixin` that both standardises the column definition and marks a model as hub-scoped for the
static isolation guard in `S6-02e`.

This subtask changes **declarative models only**. The corresponding DDL lives in `S6-01d` (additive) and
`S6-01e` (backfill + `SET NOT NULL` + constraint rebuild). Because the models declare `nullable=False`
before stage 2 has run, the two migrations must be applied together before the app is started.

## Actionables

- [ ] Add `HubScopedMixin` to `common/models/database.py`, directly below the `Base` declaration:
  ```python
  from sqlalchemy.orm import declared_attr

  class HubScopedMixin:
      """Marks a model as owned by exactly one Hub. Every query against a hub-scoped model
      MUST include `hub_id` in its WHERE clause (hubs.md §5.3)."""

      __hub_scoped__ = True          # consumed by tests/test_hub_query_guard.py (S6-02e)

      @declared_attr
      def hub_id(cls):
          return Column(
              String(36),
              ForeignKey("hubs.id", ondelete="CASCADE"),
              nullable=False,
              index=True,
          )
  ```
  - For the three **nullable** cases (`api_keys`, `mcp_servers`, `playground_sessions`) do **not** use the
    mixin; declare the column inline with `nullable=True` and set `__hub_scoped__ = False` explicitly, so
    the guard test treats them as optionally-scoped rather than mandatorily-scoped.
- [ ] Apply the mixin to the **NOT NULL** models in `common/models/database.py`, changing each class
      signature to `class X(HubScopedMixin, Base):`:
  - `AgentDefinition` (`agent_definitions`)
  - `AgentInvocationLog` (`agent_invocation_log`)
  - `WorkflowDefinition` (`workflows`)
  - `EvalTestSuite` (`eval_test_suites`)
  - `EvalRunHistory` (`eval_run_history`)
  - `EvalFlowTrace` (`eval_flow_traces`)
- [ ] Apply the mixin to the **NOT NULL** SyntraFlow models in
      `projects/syntraflow/src/database/models.py` (which already import the shared `Base`):
  - `SyntraFlowCollection` (`syntraflow_collections`)
  - `SyntraFlowDocument` (`syntraflow_documents`) — denormalised from its collection for query performance
  - `SyntraFlowChunk` (`syntraflow_chunks`) — denormalised
  - `SyntraFlowVideoSegment` (`syntraflow_video_segments`) — denormalised
  - `SyntraFlowJob` (`syntraflow_jobs`)
  - Denormalisation invariant: the ingestion pipeline must copy `hub_id` from the parent collection at
    write time. Add a docstring note on each denormalised model stating that `hub_id` is authoritative for
    scoping and must equal the parent's `hub_id`.
- [ ] Add the **nullable** `hub_id` columns inline (no mixin), per `hubs.md` §3.6:
  | Model | Table | Semantics of `NULL` |
  |---|---|---|
  | `APIKeyModel` | `api_keys` | platform-wide key |
  | `MCPServer` | `mcp_servers` | platform MCP Registry entry (vs. hub-private server) |
  | `PlaygroundSession` | `playground_sessions` | playground is user-scoped; hub is an optional context tag |
  ```python
  hub_id = Column(String(36), ForeignKey("hubs.id", ondelete="CASCADE"), nullable=True, index=True)
  ```
- [ ] Record the inherited-scope tables explicitly — they get **no** `hub_id` column and are scoped by
      joining their parent, so the guard test must not flag them:
  - `eval_test_cases` → via `suite_id` → `eval_test_suites.hub_id`
  - `eval_metric_results` → via `run_id` → `eval_run_history.hub_id`
  - `mcp_tool_cache` → via `server_id`
  - `workflow_versions` *(created later in B6-06)* → via `workflow_id`
  - Add a module-level `INHERITED_SCOPE_TABLES: dict[str, tuple[str, str]]` mapping
    `table -> (fk_column, parent_table)` in `common/models/hub_enums.py`.
- [ ] Add `physical_name` to `SyntraFlowCollection` and drop `tenant_id` from the model definition
      (`hubs.md` §3.7 and §9):
  ```python
  name = Column(String(255), nullable=False, index=True)          # was unique=True
  physical_name = Column(String(300), nullable=False, index=True) # "{hub_slug}__{name}", globally unique
  # tenant_id column REMOVED — superseded by hub_id
  ```
  - Add `def build_physical_name(hub_slug: str, name: str) -> str: return f"{hub_slug}__{name}"` to
    `projects/syntraflow/src/database/models.py` and use it as the single construction point.
  - Every Qdrant client call must switch from `collection.name` to `collection.physical_name`; enumerate
    the call sites in `projects/syntraflow/` as part of this actionable (`grep -rn "collection_name"`).
- [ ] Rebuild the uniqueness constraints per `hubs.md` §3.7 by adding `__table_args__` to each model and
      removing the old inline `unique=True`:
  ```python
  # AgentDefinition — endpoint_slug was UNIQUE globally
  __table_args__ = (UniqueConstraint("hub_id", "endpoint_slug", name="uq_agent_definitions_hub_slug"),)

  # SyntraFlowCollection
  __table_args__ = (
      UniqueConstraint("hub_id", "name", name="uq_syntraflow_collections_hub_name"),
      UniqueConstraint("physical_name", name="uq_syntraflow_collections_physical_name"),
  )

  # WorkflowDefinition — new constraint, workflows.name had none in V5
  __table_args__ = (UniqueConstraint("hub_id", "name", name="uq_workflows_hub_name"),)

  # EvalTestSuite — new constraint
  __table_args__ = (UniqueConstraint("hub_id", "name", name="uq_eval_test_suites_hub_name"),)
  ```
  - Remove `unique=True` from `AgentDefinition.endpoint_slug` and `SyntraFlowCollection.name`.
  - `mcp_servers.name` keeps its **global** unique constraint (§3.7 lists no change); note this inline so
    a later reader does not "helpfully" scope it.
- [ ] Add a `HUB_SCOPED_MODELS` registry in `common/models/__init__.py`, built by introspection rather
      than by hand so it cannot drift:
  ```python
  HUB_SCOPED_MODELS = {
      m.class_.__tablename__: m.class_
      for m in Base.registry.mappers
      if getattr(m.class_, "__hub_scoped__", False)
  }
  ```
  This registry is the input to the parameterised isolation tests and the static guard in `S6-02e`.
- [ ] Update every model docstring touched here to state the scoping rule in one line, e.g.
      `"""Agent definition. Hub-scoped: every query MUST filter by hub_id (hubs.md §5.3)."""`
- [ ] Add `tests/test_hub_scoping_models.py`:
  - Assert `HUB_SCOPED_MODELS` contains exactly the 11 NOT NULL tables from `hubs.md` §3.6.
  - Assert each of those tables has a non-nullable `hub_id` column with an index and an FK to `hubs.id`.
  - Assert `api_keys`, `mcp_servers`, `playground_sessions` have a **nullable** `hub_id`.
  - Assert `syntraflow_collections` has no `tenant_id` attribute and has `physical_name`.
  - Assert the four composite unique constraints exist by name in `Base.metadata`.
  - Assert `build_physical_name("support-kb", "faqs") == "support-kb__faqs"`.
