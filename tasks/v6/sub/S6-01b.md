# S6-01b: DatastoreBinding & AuditLog Models

> **Parent:** B6-01 (Hub Domain Model & Tenancy Foundation)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `common/models`, `common/config`

## Scope

Add the two remaining V6 platform tables: `datastore_bindings`
([`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §3.4), which lets an
ingestion hub own the physical stores that hold its data, and `audit_log` (§3.5), the append-only record
written by every mutating hub-scoped or admin endpoint. Ship the shared encryption utility that protects
`credentials_encrypted` at rest and the URI masking helper that guarantees no secret ever reaches an API
response.

Security boundary for this subtask: `credentials_encrypted` is **write-only** from the API's point of
view. It is Fernet-encrypted with `DATASTORE_ENCRYPTION_KEY`, never selected into a response model, never
logged, and never included in an `audit_log` `before_json` / `after_json` payload. `connection_uri` is
always masked before it leaves the process.

## Actionables

- [ ] Add `DATASTORE_ENCRYPTION_KEY` to the security settings block in `common/config/settings.py`,
      immediately after the existing `JWT_SECRET_KEY` field:
  ```python
  DATASTORE_ENCRYPTION_KEY: str = Field(default="", alias="DATASTORE_ENCRYPTION_KEY")
  ```
  - Empty string means "derive from `JWT_SECRET_KEY`" (dev convenience, mirroring the existing derivation
    in `gateway/services/mcp_client.py::_get_fernet`).
  - Add a validator that raises at startup when `settings.ENVIRONMENT == "production"` and the key is
    empty or equal to the shipped `JWT_SECRET_KEY` default, so production can never run on a derived key.
  - Document the variable in `.env.example` / `infrastructure/docker-compose.yml` as
    `DATASTORE_ENCRYPTION_KEY=` with the comment `# 32-byte url-safe base64 Fernet key`.
- [ ] Create `common/security/crypto.py` (new package, with `__init__.py`) exposing the shared at-rest
      encryption helpers:
  ```python
  import base64, hashlib
  from functools import lru_cache
  from typing import Optional
  from cryptography.fernet import Fernet, InvalidToken

  @lru_cache(maxsize=1)
  def _get_fernet() -> Fernet:
      """Build the Fernet instance from DATASTORE_ENCRYPTION_KEY, falling back to a
      key derived from JWT_SECRET_KEY when unset (non-production only)."""

  def encrypt_secret(plain_text: Optional[str]) -> Optional[str]:
      """Return the Fernet ciphertext, or None when `plain_text` is None/empty."""

  def decrypt_secret(cipher_text: Optional[str]) -> Optional[str]:
      """Decrypt; return None on None input and raise SecretDecryptionError on InvalidToken."""
  ```
  - `_get_fernet` derivation for the fallback path: `base64.urlsafe_b64encode(hashlib.sha256(secret.encode()).digest())`.
  - Define `class SecretDecryptionError(RuntimeError)` in the same module; never let a raw `InvalidToken`
    (which leaks key-rotation state) escape to a handler.
  - `encrypt_secret` must be non-deterministic (Fernet already includes a random IV) — do **not** add any
    caching keyed on plaintext.
- [ ] Add `mask_connection_uri(uri: str) -> str` to `common/security/crypto.py`. It is the only function
      permitted to produce a `connection_uri` for an API response:
  - `postgresql://app:s3cret@db:5432/contained` → `postgresql://app:***@db:5432/contained`
  - `http://qdrant:6333` → `http://qdrant:6333` (unchanged, no credentials present)
  - `bolt://neo4j:pw@graph:7687` → `bolt://neo4j:***@graph:7687`
  - Also strip the values of any `password`, `api_key`, `token` or `secret` query-string parameter,
    replacing each with `***`.
  - Implement with `urllib.parse.urlsplit` / `urlunsplit`; on a parse failure return the literal string
    `"***"` rather than the raw input (fail closed).
- [ ] Add `DatastoreBinding` to `common/models/database.py` per `hubs.md` §3.4:
  ```python
  class DatastoreBinding(Base):
      """A physical store owned by an ingestion hub (hubs.md §3.4)."""

      __tablename__ = "datastore_bindings"

      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      hub_id = Column(String(36), ForeignKey("hubs.id", ondelete="CASCADE"), nullable=False, index=True)
      name = Column(String(120), nullable=False)
      store_type = Column(String(20), nullable=False)          # qdrant | neo4j | postgres | opensearch
      connection_uri = Column(String(500), nullable=False)
      credentials_encrypted = Column(Text, nullable=True)      # Fernet; never serialised
      is_default = Column(Boolean, nullable=False, default=False)
      health_status = Column(String(20), nullable=False, default="unknown")
      last_health_check = Column(DateTime, nullable=True)
      config_json = Column(JSON, nullable=False, default=dict)
      created_at = Column(DateTime, default=datetime.utcnow)
      updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

      __table_args__ = (
          UniqueConstraint("hub_id", "name", name="uq_datastore_bindings_hub_name"),
          Index("ix_datastore_bindings_hub_store_type", "hub_id", "store_type"),
      )
  ```
- [ ] Add the store-type constants and the default-binding invariant:
  - In `common/models/hub_enums.py`: `STORE_TYPES: Final = ("qdrant", "neo4j", "postgres", "opensearch")`
    and `HEALTH_STATUSES: Final = ("unknown", "healthy", "unhealthy")`.
  - `@validates("store_type")` on `DatastoreBinding` rejecting values outside `STORE_TYPES`.
  - Document that **exactly one** binding per `(hub_id, store_type)` may have `is_default = True`; the
    invariant is enforced in the service layer (`S6-04b`) by clearing sibling defaults inside the same
    transaction, not by a partial unique index (kept portable for SQLite-backed tests).
- [ ] Add a `platform_default_binding(store_type: str) -> dict` helper in `common/models/hub_enums.py` (or
      a small `common/services/datastore_defaults.py`) that synthesises the read-only "Platform Default"
      binding from `common/config/settings.py` (`QDRANT_URL`, `NEO4J_URI`, `DATABASE_URL`) when a hub
      declares no binding of that type, per `hubs.md` §3.4. The synthetic binding has `id = None`,

- [ ] Add `AuditLog` to `common/models/database.py` per `hubs.md` §3.5:
  ```python
  class AuditLog(Base):
      """Append-only record of every mutating hub-scoped or admin action (hubs.md §3.5)."""

      __tablename__ = "audit_log"

      id = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
      hub_id = Column(String(36), ForeignKey("hubs.id", ondelete="SET NULL"), nullable=True, index=True)
      actor_user_id = Column(String(36), ForeignKey("users.id", ondelete="SET NULL"), nullable=True, index=True)
      action = Column(String(40), nullable=False)          # create | update | delete | archive | invite | approve | ...
      resource_type = Column(String(40), nullable=False)   # hub | agent | workflow | collection | user | ...
      resource_id = Column(String(36), nullable=True)
      summary = Column(String(255), nullable=True)
      before_json = Column(JSON, nullable=True)
      after_json = Column(JSON, nullable=True)
      ip_address = Column(String(45), nullable=True)       # 45 chars = max IPv6 textual length
      created_at = Column(DateTime, default=datetime.utcnow, index=True)

      __table_args__ = (
          Index("ix_audit_log_hub_created", "hub_id", "created_at"),
          Index("ix_audit_log_resource", "resource_type", "resource_id"),
      )
  ```
  - `hub_id` uses `ON DELETE SET NULL` (not `CASCADE`): hard-deleting an empty hub must **not** erase its
    audit history.
  - The composite `(hub_id, created_at)` index backs the `/admin/audit` reverse-chronological hub filter.

- [ ] Add `tests/test_hub_datastore_audit.py`:
  - Round-trip: `decrypt_secret(encrypt_secret("pw")) == "pw"`; `encrypt_secret(None) is None`;
    `encrypt_secret("")` returns `None`.
  - Two calls to `encrypt_secret("pw")` produce different ciphertexts (IV randomness).
  - `decrypt_secret("not-a-token")` raises `SecretDecryptionError`, not `InvalidToken`.
  - `mask_connection_uri` for each of the four store types, including a URI with `?password=hunter2`.
  - A malformed URI returns `"***"`.
