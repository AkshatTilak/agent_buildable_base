## Scope

Close out B6-02 with the two mechanisms that make tenancy violations detectable and non-mergeable. First,
a shared audit facility — one decorator plus one write helper — so that every mutating hub-scoped or admin
endpoint emits exactly one `audit_log` row per
[`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §3.5, with secrets
redacted and the actor's IP recorded. Second, the isolation test suite: a runtime suite parameterised over
every hub-scoped resource type proving a member of hub A can never reach hub B's data through any route,
and a static AST guard that fails the build when a hub-scoped model is queried by primary key alone.

The static guard is the durable part. Runtime tests prove today's routes are safe; the AST guard prevents
tomorrow's route from being written unsafely in the first place.

      audit failure must be logged loudly but must not roll back a successful business mutation:
  ```python
  async def record_audit(
      session: AsyncSession, *,
      action: str, resource_type: str,
      hub_id: str | None = None, actor_user_id: str | None = None,
      resource_id: str | None = None, summary: str | None = None,
      before: dict | None = None, after: dict | None = None,
      ip_address: str | None = None,
  ) -> None:
      """Append one audit_log row. Validates `action` against AUDIT_ACTIONS and
      `resource_type` against AUDIT_RESOURCE_TYPES; logs and swallows any write failure."""
  ```
  - Truncate `summary` to 255 chars and each of `before` / `after` to a serialised 16 KB, replacing the
    overflow with `{"_truncated": true}`.
  - The row is added to the caller's session so it commits atomically with the mutation it describes.
- [x] Add the redaction helper in the same module and apply it to every `before` / `after` payload:
  ```python
  REDACT_KEY_PATTERN = re.compile(r"credential|password|secret|token|api[_-]?key|authorization", re.I)

  def redact(payload: Mapping | None) -> dict | None:
      """Recursively replace any value whose key matches REDACT_KEY_PATTERN with '***'."""
  ```
  - Also drop the keys `credentials_encrypted` and `password_hash` entirely rather than masking them, so
    their very presence is not recorded.
  - Add a unit test asserting a nested `{"config": {"api_key": "x"}}` is redacted at depth.

  ```python
  ISOLATION_CASES = [
      # (hub_type, resource_type, route_template, method, min_role)
      ("ingestion", "collection", "/api/hubs/{hub_id}/collections/{rid}", "GET",    "viewer"),
      ("ingestion", "collection", "/api/hubs/{hub_id}/collections/{rid}", "DELETE", "maintainer"),
      ("ingestion", "document",   "/api/hubs/{hub_id}/documents/{rid}",   "GET",    "viewer"),
      ("ingestion", "job",        "/api/hubs/{hub_id}/jobs/{rid}",        "GET",    "viewer"),
      ("agent",     "agent",      "/api/hubs/{hub_id}/agents/{rid}",      "GET",    "viewer"),
      ("agent",     "agent",      "/api/hubs/{hub_id}/agents/{rid}/invoke","POST",  "contributor"),
      ("workflow",  "workflow",   "/api/hubs/{hub_id}/workflows/{rid}",   "GET",    "viewer"),
      ("workflow",  "run",        "/api/hubs/{hub_id}/workflows/{wid}/runs/{rid}", "GET", "viewer"),
      ("eval",      "eval_suite", "/api/hubs/{hub_id}/eval/suites/{rid}", "GET",    "viewer"),
      ("eval",      "eval_run",   "/api/hubs/{hub_id}/eval/runs/{rid}",   "GET",    "viewer"),
  ]
  ```
  Each case asserts all four of:
  1. *U_A* on `hub_A` with `resource_A` → `2xx` (the positive control; without it a blanket-404 bug passes).
  2. *U_A* on `hub_A` with `resource_B` (a foreign resource id under their own hub) → `404`.
  3. *U_A* on `hub_B` with `resource_B` (the correct hub, no membership) → `404`, **never** `403`.
  4. The two `404` bodies from (2) and (3) are byte-identical.
