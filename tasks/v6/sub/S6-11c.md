# S6-11c: Schema & Type Surface Cleanup

> **Parent:** B6-11 (Legacy Decommission, Data Migration & Verification)  
> **Status:** `[x]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `common/schemas`, `frontend/src/types`

---

## Scope

Remove the dead contract surface left after S6-11a and S6-11b: Pydantic models in `common/schemas/*`
and the per-project schema modules that describe removed fields, and TypeScript interfaces in
[frontend/src/types/api.ts](frontend/src/types/api.ts) that describe removed responses. The end state
is a type surface where every model corresponds to a live hub-scoped endpoint, verified by
`npx tsc --noEmit`, `ruff` and `mypy`.

Boundary: no behaviour changes here — only schema/type deletions, `hub_id` additions to the models that
survive, and the resulting import fixes.
