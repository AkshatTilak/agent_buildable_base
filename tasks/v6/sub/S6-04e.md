# S6-04e: Ingestion Hub API Routes

> **Parent:** B6-04 (Ingestion Hub — Collections & Datastore Bindings)  
> **Status:** `[x]`  
> **Complexity:** 🔴 High  
> **Owner:** `gateway/api`  

---

## Scope

Replace the flat SyntraFlow API with hub-nested routes. `projects/syntraflow/api.py` currently mounts
`/api/syntraflow/*` with `@router.post("/ingest")`, `@router.get("/jobs/{job_id}")`,
`@router.get("/documents")` and friends, none of which carry a tenancy scope. This subtask rebuilds
those surfaces under `/hubs/{hub_id}/...`, each guarded by
`require_hub(hub_type="ingestion", min_role=...)` from S6-02b, with the minimum role chosen per the
capability matrix in `hubs.md` §4.2.

The boundary is routing, request/response schemas, guards and audit writes. Manager and pipeline
behaviour comes from S6-04a–d; deletion of the legacy routes is S6-04f.

## Actionables

- [ ] Create `gateway/api/ingestion_hub.py` with
      `router = APIRouter(prefix="/hubs/{hub_id}", tags=["ingestion-hub"])` and register it in
      `gateway/main.py`; every route declares
      `ctx: HubContext = Depends(require_hub(hub_type="ingestion", min_role="<role>"))` and passes
      `ctx.hub.id` — never the raw path parameter — into the service layer.
- [ ] Implement the datastore routes (`min_role="maintainer"` for all mutations, per the "Manage
      datastore bindings" row of §4.2):
  - `GET /hubs/{hub_id}/datastores` — `min_role="viewer"`; returns bindings with masked `connection_uri`
    plus the synthetic Platform Default rows.
  - `POST /hubs/{hub_id}/datastores` — `201`; body `{name, store_type, connection_uri, credentials?, is_default?, config?}`.
  - `PATCH /hubs/{hub_id}/datastores/{binding_id}` — partial update; omitting `credentials` leaves the
    stored ciphertext untouched.
  - `DELETE /hubs/{hub_id}/datastores/{binding_id}` — `204`; `409` when in use.
  - `POST /hubs/{hub_id}/datastores/test` — `min_role="maintainer"`; tests an unsaved draft payload.
  - `POST /hubs/{hub_id}/datastores/{binding_id}/health` — forces a health check and returns the result.
- [ ] Implement the collection routes:
  - `GET /hubs/{hub_id}/collections` — `min_role="viewer"`.
  - `POST /hubs/{hub_id}/collections` — `min_role="contributor"`, `201`.
  - `GET /hubs/{hub_id}/collections/{collection_id}` — `min_role="viewer"`.
  - `PATCH /hubs/{hub_id}/collections/{collection_id}` — `min_role="contributor"` (description,
    `retrieval_config`, `datastore_binding_id`).
  - `DELETE /hubs/{hub_id}/collections/{collection_id}?force=false` — `min_role="maintainer"`
    (delete is a maintainer capability), `204`.
- [ ] Implement the document & ingestion routes (`min_role="contributor"` — ingestion is a mutating
      operation):
  - `POST /hubs/{hub_id}/documents` — multipart upload with `collection_id` as a required form field;
    keeps the existing `MAX_DOC_SIZE` / `MAX_VIDEO_SIZE` / `MAX_AUDIO_SIZE` limits and extension
    allow-list from `projects/syntraflow/api.py`; returns `202 {"job_id": ...}`.
  - `POST /hubs/{hub_id}/documents/text` — JSON body with `collection_id`, `text`, `filename`,
    chunker options.
  - `GET /hubs/{hub_id}/documents` — `min_role="viewer"`, filterable by `collection_id`, paginated.
  - `GET /hubs/{hub_id}/documents/{doc_id}/chunks` — `min_role="viewer"`.
  - `DELETE /hubs/{hub_id}/documents/{doc_id}` — `min_role="maintainer"`; cascades Qdrant + Neo4j +
    Postgres and returns the deletion counts.
- [ ] Implement the job routes: `GET /hubs/{hub_id}/jobs` and `GET /hubs/{hub_id}/jobs/{job_id}`
      (`min_role="viewer"`), both filtered by `hub_id` so a job id from another hub returns `404`.
- [ ] Implement `POST /hubs/{hub_id}/search` with `min_role="viewer"` (read-only operations are
      available to viewers) and body:
  ```json
  {
    "query": "string",
    "collection_ids": ["..."],
    "strategy": "hybrid",
    "limit": 5,
    "metadata_filter": {"tags": ["policy"]}
  }
  ```
  - Delegates to `RetrievalEngine(db, ctx.hub.id).search(...)` from S6-04d.
- [ ] Move the upload staging directory off the shared `projects/syntraflow/temp_uploads/` path to a
      per-hub subdirectory `{TEMP_UPLOAD_ROOT}/{hub_id}/`, sanitising the filename with
      `pathlib.Path(name).name` and rejecting any path component containing `..` or a separator →
      `400` (path-traversal guard).
- [ ] Write one `audit_log` row per mutating route via the shared helper, with
      `hub_id=ctx.hub.id`, `actor_user_id=ctx.user.id`, and `resource_type` ∈
      `{"datastore_binding", "collection", "document", "job"}`; read routes write nothing.
- [ ] Return the archived-hub semantics from `hubs.md` §5.2: `require_hub` yields `409 Hub is archived`
      for every mutating route in this module while still allowing the `GET` routes to serve.
- [ ] Add the response models to `common/schemas/api.py`: `CollectionResponse`,
      `DatastoreBindingResponse` (masked URI, no credentials field), `IngestionJobResponse`,
      `DocumentResponse`, `SearchHit`, `SearchResponse` — each carrying `hub_id`.
