## Scope

In Poetry 2.0+, the `poetry export` command was removed from core Poetry and extracted into the `poetry-plugin-export` package. Dockerfiles using Poetry 2.0+ (such as `infrastructure/Dockerfile.inference`) require explicit installation of `poetry-plugin-export` to generate `requirements.txt` during Docker multi-stage builds. Furthermore, recent dependency updates in `pyproject.toml` during V6 iterations require generating an updated host `poetry.lock` to avoid expensive in-container dependency re-resolution.

## Actionables

- [x] Update `infrastructure/Dockerfile.inference` to install `poetry-plugin-export`:
  ```dockerfile
  RUN pip install --no-cache-dir poetry==2.0.1 poetry-plugin-export
  ```
- [x] Run `poetry lock` on host machine to generate synchronized lock file matching `pyproject.toml`.
- [x] Verify `poetry check` passes cleanly without out-of-date lock warnings.
