# S6-10d: Eval Hub Workspace & Target Picker

> **Parent:** B6-10 (Frontend — Workflow & Eval Hub Workspaces + Admin Console)  
> **Status:** `[ ]`  
> **Complexity:** 🔴 High  
> **Owner:** `frontend/src`

---

## Scope

Build the eval hub workspace: the hub overview, the suite manager, the Agent/Workflow **target picker**
grouped by linked hub, the test-case editor with final-output *and* node-level assertions, and the run
configuration modal. This replaces the flat V5 eval surface — the suite UI in
[frontend/src/components/EvalPanel.tsx](frontend/src/components/EvalPanel.tsx) and
[frontend/src/components/eval/SuiteManager.tsx](frontend/src/components/eval/SuiteManager.tsx) — which
assumed every suite targeted a globally-addressable `agent_id`.

Boundary: results, trends, drill-down and trace replay are S6-10e. This subtask ends at "a run has been
launched".

## Actionables

- [ ] Create `frontend/src/components/hubs/eval/EvalHubOverview.tsx` at `/hubs/eval/:hubId`: suite count, cases-under-test count, last 10 runs with score chips, and a pass-rate sparkline over the last 30 days.
- [ ] Create `frontend/src/components/hubs/eval/SuiteManager.tsx` at `/hubs/eval/:hubId/suites` on the shared `DataTable`, replacing the suite list inside [frontend/src/components/eval/SuiteManager.tsx](frontend/src/components/eval/SuiteManager.tsx):
  - [ ] Columns: name, target (type icon + hub name + resource name), case count, last run score, last run status, updated-at.
  - [ ] Row actions: Open, Run, Duplicate, Export, Delete (destructive `ConfirmModal` with typed name).
  - [ ] Create/edit dialog: name, description, target selection; name uniqueness is per hub, so surface the server's `409` on duplicate name inline on the field.
- [ ] Build `frontend/src/components/hubs/eval/TargetPicker.tsx`:
  - [ ] A two-way segmented control **Agent | Workflow** that switches the option source.
  - [ ] Options grouped by source hub heading, populated **only** from hubs this eval hub has a `hub_link` to (`eval → agent`, `eval → workflow`); no globally-listed agents.
  - [ ] Empty group state: "No linked agent hubs — ask a maintainer to create a link", with a **Request link** action for `maintainer`+.
  - [ ] Emits the qualified reference `{ target_type, hub_id, target_id }` — never a bare id.
  - [ ] Renders a revoked-link warning on an existing suite whose target hub link has since been removed, blocking Run until it is resolved.
- [ ] Build `frontend/src/components/hubs/eval/TestCaseEditor.tsx` (superseding [frontend/src/components/eval/TestCaseEditor.tsx](frontend/src/components/eval/TestCaseEditor.tsx)):
  - [ ] Final-output assertions: `input_query`, `expected_output`, `expected_context`, and an assertion mode selector (`exact`, `contains`, `semantic`, `regex`, `json_path`).
  - [ ] Node-level assertions, enabled only when the suite target is a **workflow**: an assertion row = node selector + field path + operator + expected value.
  - [ ] The node selector is populated from the target workflow's **published** graph (`GET /hubs/{wf_hub_id}/workflows/{wf_id}` → published version `graph_json`), showing node label + type; a stale assertion whose node id no longer exists renders as "Node removed in v{n}" and is flagged, not silently dropped.
  - [ ] Inline add/duplicate/remove of assertion rows with keyboard support and per-row validation messages.
- [ ] Add CSV/JSON import and export controls on each suite (`POST .../suites/{id}/import`, `GET .../suites/{id}/export`) with a pre-import preview table and per-row error reporting; document the accepted column headers in the dialog.
- [ ] Build `frontend/src/components/hubs/eval/RunConfigModal.tsx` (superseding [frontend/src/components/eval/RunConfigModal.tsx](frontend/src/components/eval/RunConfigModal.tsx)):
  - [ ] Framework selector: `RAGAS`, `DeepEval`, `Both`.
  - [ ] Metric subset checkboxes filtered by the chosen framework, with per-metric threshold number inputs (0–1) and a "reset to defaults" action.
  - [ ] A summary line stating exactly what will run ("12 cases × 4 metrics against `Billing Flows / refund-triage` v9") before the confirm button.
- [ ] Add `frontend/src/store/evalSlice.ts` with `suitesByHub`, `casesBySuite`, `runsByHub`, and add hub-scoped helpers to [frontend/src/services/api.ts](frontend/src/services/api.ts) (`listSuites(hubId)`, `createSuite(hubId, …)`, `listCases(hubId, suiteId)`, `runSuite(hubId, suiteId, config)`), replacing the flat `listSuites()` / `triggerEvalRun()` helpers.
- [ ] Add tests: the target picker never lists a resource from an unlinked hub; node assertions are disabled for agent targets; import preview rejects a malformed row without partially importing.
