# S6-02a: Platform Role Refactor & Role Constants

> **Parent:** B6-02 (Hub Access Control, Scoping & RBAC v2)  
> **Status:** `[x] Completed`  
> **Complexity:** 🟡 Medium  
> **Owner:** `gateway/auth`, `common/models`

---

## Scope

Collapse the V5 three-tier global RBAC (`admin` / `editor` / `viewer`) into the V6 two-value platform role
(`admin` / `member`) described in
[`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §4.1, rename the
column `users.role` → `users.platform_role`, publish a single constants module, and update every call site
that reads a role from a token, a session, or `require_role(...)`.

`require_role` survives only for **platform-level** endpoints (`/admin/*`, `/models` writes, `/mcp` writes,
`/infrastructure` proxies) narrowed to `admin` / `member`. Hub-scoped endpoints must not use it at all —
they move to `require_hub(...)` in `S6-02b`. This is a hard cutover: no `editor` / `viewer` alias is
retained anywhere.

  ```python
  def require_role(*allowed_roles: str) -> Callable:
      """Platform-level RBAC only. Hub-scoped routes MUST use require_hub() (hubs.md §5.2)."""
      unknown = set(allowed_roles) - set(PLATFORM_ROLES)
      if unknown:                      # fail at import time, not at request time
          raise ValueError(f"Unknown platform role(s): {sorted(unknown)}. Valid: {PLATFORM_ROLES}")

      async def role_checker(request: Request) -> Dict[str, Any]:
          user = await get_current_user(request)
          role = user.get("platform_role", PLATFORM_ROLE_MEMBER)
          if role == PLATFORM_ROLE_ADMIN or role in allowed_roles:
              return user
          raise HTTPException(status_code=403, detail="Insufficient platform permissions")
      return role_checker
  ```
