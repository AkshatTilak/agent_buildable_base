# S6-05c: Agent Hub CRUD & Invocation Routes

> **Parent:** B6-05 (Agent Hub — Scoped Agent Lifecycle)  
> **Status:** `[x]`  
> **Complexity:** 🔴 High  
> **Owner:** `gateway/api`  

---

## Scope

Rewrite [`gateway/api/agent_crud.py`](file:///c:/Akshat/ContAIned/gateway/api/agent_crud.py) and
[`gateway/api/agent_invoke.py`](file:///c:/Akshat/ContAIned/gateway/api/agent_invoke.py) so every agent
route is nested under `/hubs/{hub_id}/agents`, guarded by `require_hub(hub_type="agent", min_role=...)`,
and reads/writes exclusively through the hub-scoped repository from S6-05a. The SSE streaming behaviour,
smart-routing endpoint, batch invoke and stats endpoints from V5 are preserved verbatim in
functionality — only their addressing, authorisation and query scoping change.

Every mutating route writes exactly one `audit_log` row. The flat `/agents` prefix is *not* removed in
this subtask (that is S6-05e's deletion pass) but no new behaviour may be added to it.

## Actionables

- [ ] Change the router declaration in [`gateway/api/agent_crud.py`](file:///c:/Akshat/ContAIned/gateway/api/agent_crud.py) from `APIRouter(prefix="/agents", ...)` to `APIRouter(prefix="/hubs/{hub_id}/agents", tags=["agent-hub"])` and add `ctx: HubContext = Depends(require_hub(hub_type="agent", min_role=...))` to every operation.
- [ ] Implement the CRUD route table with the exact minimum roles below (roles per [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §4.2):

  | Method | Path | Min role | Notes |
  |---|---|---|---|
  | `GET` | `/hubs/{hub_id}/agents` | `viewer` | supports `?is_active=`, `?q=` name search |
  | `POST` | `/hubs/{hub_id}/agents` | `contributor` | `201`, slug generated per hub |
  | `GET` | `/hubs/{hub_id}/agents/{agent_id}` | `viewer` | |
  | `PUT` | `/hubs/{hub_id}/agents/{agent_id}` | `contributor` | |
  | `PATCH` | `/hubs/{hub_id}/agents/{agent_id}/toggle` | `contributor` | activate/deactivate |
  | `DELETE` | `/hubs/{hub_id}/agents/{agent_id}` | `maintainer` | `204` |
  | `POST` | `/hubs/{hub_id}/agents/{agent_id}/duplicate` | `contributor` | new slug, same hub |

- [ ] Move the model-dropdown endpoint off the agent path: `GET /hubs/{hub_id}/agents/models` currently shadows `GET /agents/{agent_id}`. Relocate it to `GET /hubs/{hub_id}/agents/available-models` (min role `viewer`) and keep the `ModelRegistryModel` query filtered to `role in ("completion","classifier")` and `is_enabled == True`.
- [ ] Replace every inline `select(AgentDefinition).where(AgentDefinition.id == agent_id)` with the repository calls from S6-05a so `hub_id` is always in the `WHERE` clause. A miss returns `404` with `{"error": {"code": "AGENT_NOT_FOUND"}}` — never `403`, so agent ids in other hubs are not enumerable.
- [ ] On create/update, call `validate_bindings(...)` from S6-05b before commit; propagate `HUB_LINK_REQUIRED` / `CROSS_HUB_REFERENCE_MISMATCH` unchanged rather than wrapping them in a generic `500`.
- [ ] Change the invoke router in [`gateway/api/agent_invoke.py`](file:///c:/Akshat/ContAIned/gateway/api/agent_invoke.py) to the nested prefix and implement:

  | Method | Path | Min role |
  |---|---|---|
  | `POST` | `/hubs/{hub_id}/agents/{agent_id}/invoke` | `contributor` |
  | `POST` | `/hubs/{hub_id}/agents/{agent_id}/batch-invoke` | `contributor` |
  | `POST` | `/hubs/{hub_id}/agents/route` | `contributor` |
  | `GET` | `/hubs/{hub_id}/agents/{agent_id}/stats` | `viewer` |
  | `GET` | `/hubs/{hub_id}/agents/{agent_id}/logs` | `viewer` |

- [ ] Remove the `id OR endpoint_slug` disjunction from `invoke_agent`. Resolution is strictly by primary key within the hub; slug-based addressing exists only on the external API (S6-05d). Keep the `403` for `is_active is False` with code `AGENT_INACTIVE`.
- [ ] Preserve SSE streaming exactly as in V5: when `payload.stream is True` return a `StreamingResponse(..., media_type="text/event-stream")` emitting `data: {json}\n\n` chunks terminated by `data: [DONE]\n\n`. Resolve bindings and the hub link **before** the generator is returned so a `HUB_LINK_REVOKED` surfaces as a clean `403` rather than mid-stream.
- [ ] Scope routing and stats to the hub:
  - `POST .../agents/route` may only select candidate agents where `hub_id == ctx.hub.id and is_active == True`; the round-robin counter becomes a per-hub dict `_rr_counter: dict[str, int]` keyed by `hub_id`
  - `GET .../stats` aggregates `AgentInvocationLog` filtered by both `agent_id` and `hub_id`
- [ ] Set `hub_id` on every log write: `log_invocation_background(...)` gains a required `hub_id: str` parameter and persists it on `AgentInvocationLog`. Update all call sites.
- [ ] Write an audit row for every mutating route via the S6-02e helper, e.g. `await write_audit(session, hub_id=ctx.hub.id, actor_user_id=ctx.user.id, action="create", resource_type="agent", resource_id=agent.id, after_json=AgentResponse.model_validate(agent).model_dump())`. Invoke routes are **not** audited (they are covered by the invocation log).
- [ ] Include `hub_id` in the `agent-config-updates` Redis publish payloads emitted from create/update/delete/toggle so `AgentRuntimeManager` can key its cache correctly.
- [ ] Register the routers in [`gateway/main.py`](file:///c:/Akshat/ContAIned/gateway/main.py) under the existing API prefix and confirm no duplicate operation ids are generated by the nested paths.
