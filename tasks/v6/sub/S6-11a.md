> **Parent:** B6-11 (Legacy Decommission, Data Migration & Verification)  
> **Status:** `[x]`  
> **Complexity:** 🔴 High  
> **Owner:** `gateway`, `projects`

## Scope

Delete every backend route, module, dependency and symbol that the hub architecture replaces, exactly
as enumerated in `hubs.md` §9. This is a hard cutover: no aliases, no deprecation shims, no
`include_router` kept "just in case". Each removal below names the file the symbol lives in today and
the grep pattern that proves it is gone.

Boundary: schema/Pydantic surface cleanup is S6-11c, the frontend sweep is S6-11b, and the automated
guard script is S6-11e. This subtask only removes backend code and adjusts the routers that mount it.
