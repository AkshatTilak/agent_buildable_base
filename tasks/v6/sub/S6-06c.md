## Scope

In V5 an `AgentNode` stored a bare `agent_id` and a `RetrievalNode` a bare collection name, both
resolved against a single global namespace. V6 requires a **qualified reference** object
`{type, hub_id, resource_id}` on every node that points at a resource outside its own workflow, and that
reference must be validated through `hub_resolver` at three points: on canvas edit, on publish, and
again immediately before the node executes.

This subtask extends
[`projects/guardroute/src/core/graph_parser.py`](file:///c:/Akshat/ContAIned/projects/guardroute/src/core/graph_parser.py)
with reference-aware validation and a precise per-node error payload. The V5 node catalogue
(`SUPPORTED_NODE_TYPES`), the DAG/cycle rules and the strict terminal-node constraint
(`TERMINAL_NODE_TYPES`) are **retained unchanged** — this is an additive validation pass, not a rewrite
of graph semantics.

## Actionables

- [ ] Define the reference schema in `common/schemas/workflows.py`:
  ```python
  class NodeReference(BaseModel):
      type: Literal["agent", "collection", "workflow", "mcp_tool"]
      hub_id: str
      resource_id: str
  ```
  Serialised on the node as `data["reference"]`. Keep the wire form from [`workflow_v6.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/workflow_v6.md) §4 (`{"type": "agent", "hub_id": "...", "agent_id": "..."}`) accepted on input by normalising `agent_id` / `collection_id` into `resource_id`, and always **emit** the canonical `resource_id` form.
- [ ] Add a `NODE_REFERENCE_REQUIREMENTS` map in the parser declaring which node types require which reference type, so validation is table-driven rather than a chain of `if`s:
  ```python
  NODE_REFERENCE_REQUIREMENTS = {
      "AgentNode": "agent", "agent": "agent",
      "MultiAgentNode": "agent",           # list-valued: data["references"]
      "RetrievalNode": "collection", "retrieval": "collection",
      "MCPToolNode": "mcp_tool", "mcp_tool": "mcp_tool",
  }
  ```
  `MultiAgentNode` carries `data["references"]: list[NodeReference]`; all others carry a single `data["reference"]`.
- [ ] Add `GraphParser.validate_references(self, graph_json, *, session, source_hub_id) -> list[NodeValidationError]` (async). For each node requiring a reference it must:
  - Assert the reference object is present and well-formed → `MISSING_REFERENCE` / `MALFORMED_REFERENCE`
  - Assert `reference.type` matches the node's requirement → `REFERENCE_TYPE_MISMATCH`
  - Call `common/services/hub_resolver.py::resolve_linked(session, source_hub_id=source_hub_id, target_resource_type=reference.type, target_resource_id=reference.resource_id)`
  - **Cross-hub security check:** confirm the resolved resource's own `hub_id` equals `reference.hub_id` (a linked hub id paired with a third hub's resource id must fail), that a `hub_link` exists in the allowed direction (`workflow → agent`, `workflow → ingestion` per [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §3.3), that links are treated as **non-transitive**, and that the target hub is not archived
  - Assert the referenced agent/collection is active/available → `REFERENCE_INACTIVE`
- [ ] Standardise the error payload so the editor can focus the offending node:
  ```json
  { "is_valid": false,
    "errors": [
      { "node_id": "node_agent_2", "node_type": "AgentNode",
        "code": "HUB_LINK_REQUIRED",
        "message": "Workflow hub 'billing-flows' is not linked to agent hub 'support-agents'.",
        "field": "data.reference",
        "reference": { "type": "agent", "hub_id": "hub_9f2", "resource_id": "agt_31c" } }
    ],
    "warnings": [] }
  ```
  Error codes: `MISSING_REFERENCE`, `MALFORMED_REFERENCE`, `REFERENCE_TYPE_MISMATCH`, `CROSS_HUB_REFERENCE_MISMATCH`, `HUB_LINK_REQUIRED`, `HUB_LINK_REVOKED`, `REFERENCE_TARGET_MISSING`, `REFERENCE_INACTIVE`, `HUB_ARCHIVED`.
- [ ] Keep the existing topology checks intact and fold them into the same payload rather than raising early: non-empty `nodes`, all edges reference known node ids, no cycles (Kahn's algorithm as implemented today), and every leaf must be in `TERMINAL_NODE_TYPES`. Emit them with codes `EMPTY_GRAPH`, `DANGLING_EDGE`, `CYCLE_DETECTED`, `NON_TERMINAL_LEAF`. Retain `GraphValidationError` for callers that want the raise-based API.
- [ ] Add the single validation entry point used by every caller:
  ```python
  async def validate_workflow_graph(session, *, graph_json: dict, source_hub_id: str,
                                    strict: bool = False) -> ValidationResult
  ```
  `strict=False` (edit/autosave) reports reference problems as errors but still stores the draft; `strict=True` (publish, execute) refuses.
- [ ] Wire the three validation points:
  - **Edit** — `version_service.update_draft` (S6-06b) calls it with `strict=False` and persists the result into `workflow_versions.is_valid` / `validation_json`
  - **Publish** — `version_service.publish` calls it with `strict=True` and raises on any error
  - **Execute** — the run orchestrator (S6-06d) re-resolves each node's reference immediately before that node runs, failing the run with `HUB_LINK_REVOKED` rather than reading across the boundary
- [ ] Update `GraphParser.build_graph` / `parse_graph_json_to_langgraph` so node constructors receive the **resolved** resource (agent definition, collection + its datastore binding) rather than looking it up by bare id, and remove any global-namespace lookup left in the node executors under [`projects/guardroute/src/nodes/`](file:///c:/Akshat/ContAIned/projects/guardroute/src/nodes) — in particular `multi_agent_executor.py`, `router_executor.py` and `eval_executor.py`.
- [ ] Add a reference-extraction helper `def collect_references(graph_json: dict) -> list[tuple[str, NodeReference]]` returning `(node_id, reference)` pairs; used by export/import remapping (S6-06f), by the "hubs this workflow depends on" badge, and by the migration rewrite (S6-06g).
- [ ] Add `tests/test_workflow_graph_refs.py` covering: a bare `agent_id` node fails with `MISSING_REFERENCE`; a valid linked reference passes; deleting the link makes the same graph fail with `HUB_LINK_REQUIRED`; a reference pairing a linked `hub_id` with another hub's `resource_id` fails with `CROSS_HUB_REFERENCE_MISMATCH`; the V5 terminal-node and cycle tests in [`tests/test_v2_graph_parser.py`](file:///c:/Akshat/ContAIned/tests/test_v2_graph_parser.py) still pass unchanged.
