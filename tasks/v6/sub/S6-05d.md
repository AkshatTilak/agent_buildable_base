# S6-05d: Hub-Qualified External API & Scoped API Keys

> **Parent:** B6-05 (Agent Hub — Scoped Agent Lifecycle)  
> **Status:** `[x]`  
> **Complexity:** 🔴 High  
> **Owner:** `gateway/api`, `gateway/auth`  

---

## Scope

The OpenAI-compatible surface in [`gateway/api/external.py`](file:///c:/Akshat/ContAIned/gateway/api/external.py)
currently resolves an agent by matching `req.model` against a globally unique `endpoint_slug`. With
`UNIQUE (hub_id, endpoint_slug)` that lookup is ambiguous and is replaced by the hub-qualified form
`"{hub_slug}/{agent_slug}"`. The bare-slug form is removed outright — no fallback, no deprecation alias.

In parallel, `api_keys` gains a nullable `hub_id`: a key with `hub_id` set may only address agents in
that one hub; a platform key (`hub_id IS NULL`) may address any agent reachable by the key's owning user
through hub membership. `GET /v1/models` is filtered by the same authorisation rules so a key never
learns that an agent it cannot call exists.

  ```python
  QUALIFIED_MODEL_RE = re.compile(r"^(?P<hub_slug>[a-z0-9][a-z0-9-]{0,63})/(?P<agent_slug>[a-z0-9][a-z0-9-]{0,99})$")

  async def resolve_qualified_agent(
      session, *, model: str, api_key_hub_id: str | None, api_key_user_id: str | None
  ) -> AgentDefinition | None:
      """Returns the agent for '{hub_slug}/{agent_slug}', or None if `model` is not
      hub-qualified (caller then treats it as a raw model id). Raises HTTPException
      for authorisation failures."""
  ```
  - Match `hub_slug` against `hubs.slug` where `hub_type == "agent"` and `is_archived == False`
  - Then `AgentDefinition.hub_id == hub.id`, `endpoint_slug == agent_slug`, `is_active == True`
- [ ] Implement the authorisation rules exactly:

  | Key type | Rule | Failure |
  |---|---|---|
  | Hub-scoped (`api_keys.hub_id` set) | `hub.id == api_key.hub_id` | `404 MODEL_NOT_FOUND` |
  | Platform (`hub_id IS NULL`) with owning user | user must be a `hub_members` row on that hub with role ≥ `contributor`, or platform `admin` | `404 MODEL_NOT_FOUND` |
  | Platform key with no owning user | reject all hub-qualified models | `403 KEY_NOT_BOUND_TO_USER` |

  Authorisation failures deliberately return `404 MODEL_NOT_FOUND` (not `403`) to prevent agent/hub enumeration, mirroring [`hubs.md`](file:///c:/Akshat/ContAIned/agent_buildable_base/references/logic/hubs.md) §5.2.
