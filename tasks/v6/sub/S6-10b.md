# S6-10b: Versioned Workflow Editor

> **Parent:** B6-10 (Frontend — Workflow & Eval Hub Workspaces + Admin Console)  
> **Status:** `[ ]`  
> **Complexity:** 🔴 High  
> **Owner:** `frontend/src`

---

## Scope

Rework [frontend/src/components/WorkflowCanvas.tsx](frontend/src/components/WorkflowCanvas.tsx) into
`components/hubs/workflow/WorkflowEditor.tsx`, a per-workflow editor addressed by
`/hubs/workflow/:hubId/workflows/:wfId`, and rewrite
[frontend/src/store/workflowSlice.ts](frontend/src/store/workflowSlice.ts) to the shape mandated by
`workflow_v6.md` §5 — deleting the singleton `workflows` / `activeWorkflow` / `selectedNodeId` /
`drawerOpen` surface in favour of `workflowsByHub`, `editorState`, `runsByWorkflow`.

The editor adds everything V5 lacked: debounced draft autosave with optimistic locking, an explicit
save-state indicator, a non-destructive conflict dialog, a version rail with diff and restore, an
always-visible validation strip, hub-grouped resource pickers in the property drawer, keyboard
shortcuts, a navigation guard and a bounded undo/redo stack. Node types, the graph parser and terminal
constraints are unchanged from V5 and are out of scope.

## Actionables

- [ ] Rewrite [frontend/src/store/workflowSlice.ts](frontend/src/store/workflowSlice.ts):
  - [ ] **Delete** the `Workflow.graph_json` singleton interface usage, `workflows`, `activeWorkflow`, `setWorkflows`, `setActiveWorkflow` — no `currentWorkflow`/`nodes`/`edges` field may remain anywhere in the slice.
  - [ ] Add `workflowsByHub: Record<string, WorkflowSummary[]>`, `editorState: { workflowId: string | null; graph: WorkflowGraph; versionEtag: string | null; dirty: boolean; validation: ValidationResult | null; saveState: 'idle' | 'saving' | 'saved' | 'conflict' | 'publishing' }`, and `runsByWorkflow: Record<string, WorkflowRun[]>`.
  - [ ] Add a bounded history stack `history: { past: WorkflowGraph[]; future: WorkflowGraph[] }` capped at 50 entries, with `pushHistory`, `undo`, `redo` actions that drop the oldest entry past the cap.
- [ ] Create `frontend/src/components/hubs/workflow/WorkflowEditor.tsx` that loads the draft version via `GET /hubs/{hub_id}/workflows/{wf_id}` and hydrates `editorState.graph` + `versionEtag` from the response, replacing the V5 single-graph load path.
- [ ] Implement draft autosave in `frontend/src/components/hubs/workflow/useDraftAutosave.ts`:
  - [ ] Debounce 2 s of canvas idle, then `PUT /hubs/{hub_id}/workflows/{wf_id}/draft` with header `If-Match: <versionEtag>`.
  - [ ] Store the new etag from the response; never fire two in-flight saves concurrently (queue the latest graph instead).
  - [ ] Flush pending saves on `beforeunload` and on explicit `Cmd/Ctrl+S`.
- [ ] Add an editor header save-state chip rendering exactly one of `Saved • v7 draft`, `Unsaved changes`, `Saving…`, `Publishing…`, `Conflict` — never an ambiguous silent state — plus a **Publish** button hitting `POST .../publish`.
- [ ] Build `frontend/src/components/hubs/workflow/ConflictDialog.tsx` opened on a `409` from the draft PUT:
  - [ ] Shows the server's returned graph summary (nodes/edges changed, author, timestamp).
  - [ ] Offers **Reload server version** (discard local, rehydrate etag) and **Copy my changes** (copies the local graph JSON to clipboard *and* downloads it) — neither option may silently overwrite the server.
- [ ] Build `frontend/src/components/hubs/workflow/VersionRail.tsx`:
  - [ ] Lists versions from `GET .../versions` with `version_number`, author, `change_note`, timestamp and an `is_valid` indicator.
  - [ ] Two-version selection produces an inline diff of nodes/edges **added / removed / changed** computed in `frontend/src/components/hubs/workflow/graphDiff.ts`.
  - [ ] **Restore** calls `POST .../versions/{v}/restore` and reopens the result as the current draft with a confirmation step.
- [ ] Build `frontend/src/components/hubs/workflow/ValidationStrip.tsx`: always visible (collapsed to a one-line summary when clean), fed by `POST .../validate` and by `validation_json` on the draft; clicking an error calls ReactFlow `setCenter` on the offending node id and applies a `.node-error` outline class.
- [ ] Rework [frontend/src/components/PropertyDrawer.tsx](frontend/src/components/PropertyDrawer.tsx) resource pickers:
  - [ ] Agent picker (used by `nodes/AgentNode.tsx`, `nodes/MultiAgentNode.tsx`, `nodes/RouterNode.tsx`) groups options by source **agent hub**, populated from the workflow hub's `hub_links`.
  - [ ] Collection picker (used by `nodes/RetrievalNode.tsx`) groups by source **ingestion hub** the same way.
  - [ ] Persist qualified references `{ "type": "agent", "hub_id": "…", "agent_id": "…" }` — a bare id must never be written into `graph_json`.
  - [ ] Render a "Link required" badge and an inline **Request link** action (visible to `maintainer`+ on the source hub) when a referenced hub is unlinked or the link was revoked.
- [ ] Implement keyboard shortcuts in `frontend/src/components/hubs/workflow/useEditorShortcuts.ts`: `Cmd/Ctrl+S` publish, `Cmd/Ctrl+D` duplicate selected node, `Del`/`Backspace` delete selection, `Cmd/Ctrl+Z` undo, `Cmd/Ctrl+Shift+Z` redo — all suppressed while focus is inside an input or textarea.
- [ ] Add an unsaved-changes navigation guard using a React Router blocker that fires when `editorState.dirty` is true, offering *Save draft & leave* / *Discard* / *Stay*.
- [ ] Update `frontend/src/App.tsx` routing so `/workflow` no longer exists and `WorkflowEditor` is reached only through the hub-scoped path; delete `WorkflowCanvas.tsx` once the editor is at parity (tracked for verification in S6-11b).
- [ ] Add tests covering: autosave sends `If-Match`, a `409` opens the conflict dialog without mutating the local graph, undo/redo stays within the 50-entry cap, and the validation strip focuses the reported node id.
