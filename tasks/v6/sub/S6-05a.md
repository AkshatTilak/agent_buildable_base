# S6-05a: Hub-Scoped Agent Model & Service

> **Parent:** B6-05 (Agent Hub — Scoped Agent Lifecycle)  
> **Status:** `[ ]`  
> **Complexity:** 🟡 Medium  
> **Owner:** `common/models`, `common/services`  

---

## Scope

Make the agent domain model tenant-aware. `AgentDefinition` and `AgentInvocationLog` in
[`common/models/database.py`](file:///c:/Akshat/ContAIned/common/models/database.py) gain a `NOT NULL`
`hub_id`, the global `UNIQUE` on `agent_definitions.endpoint_slug` is replaced by
`UNIQUE (hub_id, endpoint_slug)`, and slug generation becomes hub-local so two hubs may each own an
agent called `support-bot`. `common/services/agent_runtime.py` is reworked so the in-memory cache is
keyed by `(hub_id, agent_id)` and every load path requires an explicit `hub_id`.

The boundary of this subtask is the **model and service layer only**. Collection binding
(S6-05b), route surfaces (S6-05c), the external API (S6-05d) and the migration (S6-05e) are out of
scope here; this subtask only ships the columns, constraints, repository helpers and runtime cache that
those depend on.
